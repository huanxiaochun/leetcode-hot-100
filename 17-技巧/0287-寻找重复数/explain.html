287. 寻找重复数

中等 技巧 LeetCode ↗

把下标 i 当结点、i → nums[i] 当箭头，数组就成了一条带环的链表。重复的数有两个箭头指向它，正是环的入口。用 142 题的快慢指针：先在环里相遇，再一个回起点、同速走，相遇处就是答案。

nums（蓝：慢指针所在下标，橙：快指针）
看成链表：结点是下标 i，箭头指向 nums[i]（红色虚线是指向同一个结点的两条箭头）

  

  

  



  

    
为什么这个技巧成立

    
把下标 i 当结点、i → nums[i] 当箭头：值都在 1 ~ n，从 0 出发永远走不出去，一定会走进一个环

    
1
重复的数 x 有两个下标都指向它：一个来自环外、一个来自环里，所以 x 就是环的入口
2
第一阶段：慢指针一次 1 步、快指针一次 2 步。进环以后快的每轮追近一步，一定会在环里相遇
3
相遇时慢走了 a + b，快走了 a + b + kL（多绕了 k 圈），又因为快 = 2 × 慢，推出 a = (k−1)L + c
4
第二阶段：一个从起点、一个从相遇点，都一次 1 步。走 a 步后，前者到入口；后者走了 c 再加整圈，也到入口
慢 = a + b相遇时慢指针走的
快 = a + b + kL快的多绕了 k 圈
快 = 2 × 慢 ⇒ a + b = kL
a = kL − b = (k−1)L + c
a 步（起点到入口）= c 步（相遇点到入口）再加 k−1 整圈：两个指针同速走，一定在入口相遇

  

  

    
归纳 · 同类题 · 易错点

    
判圈（Floyd 快慢指针）把数组看成链表，重复数就是环的入口

    
142环形链表 II
完全一样的两阶段：next 指针换成了 nums[i]，结点换成了下标
141环形链表
只做第一阶段：快慢指针相遇就说明有环
41缺失的第一个正数
那题用原地哈希（把数换到它该在的位置、或者标负号）。本题不许改数组，只能把数组当成链表来走

    
从下标 0 出发值都在 1 ~ n，没有箭头指向 0，所以 0 一定在环外，从它出发才能保证走到「入口」。从别的下标出发可能本来就在环里
先走再判断一开始 slow == fast == 0。用 while 先判断会直接退出，要用 do-while（Python 用 while True + break）

  
  

    

      
时间O(n)

      

        
第一阶段 ≤ a + L 轮+第二阶段 a 步

        
慢指针进环前走 a 步；进环以后快指针每轮追近 1 步，不到一圈（L 步）就追上。第二阶段再走 a 步。a 和 L 都不超过 n。

      

    

    

      
空间O(1)

      

        
两个指针 slow、fast

        
链表是「想象」出来的：下一个结点就是 nums[当前]，不用真的建链表，也不用记走过哪些点。

      

    

    

      
对比哈希 / 排序

      

        
哈希集合记录见过的数：O(n) 空间。排序后看相邻：要改数组。标负号做原地标记：也改了数组。题目要求不修改数组、O(1) 空间，这三种都不行；按值域二分（数 ≤ mid 的个数）也满足要求，但是 O(n log n)。
