三个指针把数组分成四段：[0, lo) 是 0、[lo, i) 是 1、(hi, n) 是 2、[i, hi] 还没看。i 遇到 0 就换到前面，遇到 2 就换到后面，遇到 1 就留下，一趟扫完。

归纳 · 同类题 · 易错点

    
三指针分区（荷兰国旗）一趟扫描，把数组分成三段

    
283移动零
两段版本：只有一个分界指针，非零的往前换。本题多一个从右往左的 hi，分成三段
912排序数组 / 快速排序的三路划分
完全相同的过程：把基准当成 1，小于基准的当 0、大于的当 2。有大量重复元素时，三路划分让快排不退化
41缺失的第一个正数
同样是原地交换，把每个数换到它「该在」的位置；那题位置由数值决定，这题只有三种位置

    
和 hi 交换后 i 不能前进从后面换过来的可能是 0 或 2，还没检查。i++ 就漏掉了：[2, 0, 1] 会得到 [0, 2, 1]（应该是 [0, 1, 2]）
循环条件是 i ≤ hi(hi, n) 已经全是 2，i 越过 hi 就该停；写成 i < n 会把 2 区的数又换回来

  
  

    

      
时间O(n)

      

        
每一步 i 右移或 hi 左移→最多 n 步

        
「还没看」的 [i, hi] 每一步都缩短一格：遇到 0、1 是 i 右移，遇到 2 是 hi 左移。所以只扫一趟。

[i, hi] 每步少一格，变空就结束

    

    

      
空间O(1)

      

        
三个指针 lo、i、hi

        
全部原地交换，不需要额外数组。

      

    

    

      
对比计数 两趟

      

        
计数排序：先数出 0、1、2 各有几个，再按个数回填，也是 O(n)、O(1)，但要扫两趟；题目进阶要求一趟。直接 sort 是 O(n log n)。
