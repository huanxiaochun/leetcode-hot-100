题目类型每一层能选什么下一层传什么什么时候收集剪枝

      
79. 单词搜索网格搜索上下左右 4 个邻格邻格，k + 1拼到最后一个字母出界 / 字母不对 / 走过
51. N 皇后棋盘第 r 行的每一列r + 1r == n列 / 两条对角线被占

    

    
和 51 一样在二维网格上，区别是：79 是一条路径（下一步只能走邻格），51 是每行放一个（下一层是下一行）。79 只要找到一个就停（|| 短路），51 要找出所有摆法。

    
一定要改回原字母找不到时不改回来，这些格子就一直是 #，换一个起点时就走不了，本来能拼出的单词会返回 false。
先判断再标记判断出界、判断字母都要在改成 # 之前；否则会把 # 和 word[k] 比，或者访问越界。

  

  

    

      
时间O(m · n · 3ᴸ)

      

        
m·n 个起点×每步最多 3 个新方向（不走回头路），走 L 步

        
从起点出发第一步有 4 个方向，之后来的那个方向已经是 #，最多 3 个新方向。L 是 word 的长度。实际上字母对不上的分支第一步就被剪掉了，远远跑不满。

      

      
A→B→C↑↓→
走到 C：来的方向 ← 已经是 #

    

    

      
空间O(L)

      

        
递归深度最多 L

        
直接把 board 上走过的格子改成 #，不用另开 visited 数组；回来时一定要改回原字母，不然别的起点就走不了这些格子。

如果找不到时不把 # 改回来，后面换一个起点时，那些格子永远是 #，本来能拼出的单词也会返回 false。另一个常见的错：用全局 visited 但只在找到时才清理。
