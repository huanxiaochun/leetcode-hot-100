切割就是组合：在 n − 1 个缝里选哪些下刀。每一层决定「下一刀切在哪」，切下的那段必须满足条件。

131. 分割回文串切割这一刀切在 start 后面哪里end + 1start == n这段不是回文
78. 子集子集start 往后的数i + 1每个节点不用（start 已去重）
39. 组合总和组合start 往后的数i（可重复选）rest == 0c[i] > rest 就 break

    

    
把「切在 end 后面」看成「选了 end」，就和 78 子集一样是 start 往后选、下一层传 end + 1。区别是切割的收集时机是 start == n（切到最后），而且每一段要先检查是不是回文。

    
pal 表的计算顺序pal[i][j] 依赖 pal[i + 1][j − 1]，所以 i 从后往前算。i 从前往后会用到还没算好的值。
子串的写法C++ 是 s.substr(start, 长度)，第二个参数是长度 end − start + 1，不是结束下标。

  

  

    

      
时间O(n · 2ⁿ)

      

        
n − 1 个缝，每个切或不切→最多 2ⁿ⁻¹ 种切法，每种拷贝 O(n)

        
dp 预处理 O(n²)，之后判断一段是不是回文只要 O(1) 查表。最坏是全部相同的字母（如 "aaaa"），每种切法都合法。

      

      
aab
3 个字母有 2 个缝：最多 2² = 4 种切法

    

    

      
空间O(n²)

      

        
pal 表 n × n+递归深度 n

        
pal[i][j] 依赖 pal[i + 1][j − 1]（左下角那格），所以 i 要从后往前算。

      

    

    

      
对比现场判回文

      

        
不预处理也能做：每次切的时候用双指针检查这一段是不是回文，O(n)。同一段会被反复检查很多次，总共多一个 n 的因子。dp 表把重复的检查省掉了。
