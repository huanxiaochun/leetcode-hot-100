三道题只差下一层传什么：46 每层从 0 开始（靠 used 去重）；78 传 i + 1（每个数最多选一次）；39 传 i（还能再选自己，但不回头）。

    
不排序就不能 break不排序时，c[i] > rest 只能 continue，因为后面可能还有小的数。排序后才能直接 break。
传 i 不是 i + 1传 i + 1 每个数只能用一次，[2,2,3] 就找不到了；传 0 又会出现 [2,3,2] 这样的重复。

空间O(target)

      

        
最深是一直选最小的数→target / min 层

        
每层至少减掉最小的那个数，所以递归深度不超过 target / min(candidates)。

      

    

    

      
对比为什么要 start

      

        
如果每层都从下标 0 开始挑，会同时得到 [2,2,3]、[2,3,2]、[3,2,2]，同一个组合算了好几次。规定只能从 start 往后选（不回头），每个组合就只按从小到大的顺序出现一次。
