22. 括号生成

中等 回溯 LeetCode ↗

一个一个位置放括号。左括号只要还没用完（open < n）就能放；右括号只有在前面左括号比右括号多（close < open）时才能放，否则一定配不上。放满 2n 个就一定合法。

path：一共 2n 个位置，下面的数字是「左括号比右括号多几个」
决策树：节点是此时的 path；每个节点最多两条路：放 ( 或放 )
当前路径 刚撤销（回到上一层） 剪枝 找到答案 已经走完 

  

  

  



  

    
回溯五问写代码前先回答这五个问题，代码就出来了

    

      
  1. ①
    path 是什么
    已经放好的括号串，以及用了几个 (（open）、几个 )（close）。
  2. ②
    每一层能选什么
    只有两种：放 ( 或放 )。
  3. ③
    什么时候收集答案
    path.size() == 2n：放满了，一定合法。
  4. ④
    剪枝条件
    open < n 才能放 ( ；close < open 才能放 ) 。
  5. ⑤
    撤销了什么
    path.pop_back()；open / close 是参数，回来自动还原。

和 17 一样每层填一个位置。区别是能不能放要看前面放了什么：前缀里右括号不能比左括号多。51 也一样，这一行能放哪列取决于上面几行。

    
条件是 close < open写成 close < n 会生成 "())(" 这种非法串。右括号的上限是已经放的左括号数。
两个 if 不是 if-else能放 ( 和能放 ) 是两个独立的分支，两个都要试。写成 else 会漏掉一半答案。
