  1. ①
    path 是什么
    已经选进来的数，比如 [1, 3]。
  2. ②
    每一层能选什么
    只能选 start 后面的数：下标递增地选，[1, 3] 只会以这个顺序出现一次，不会再出现 [3, 1]。
  3. ③
    什么时候收集答案
    每个节点都是一个子集，一进 dfs 就收集，不用等到叶子。
  4. ④
    剪枝条件
    不需要：start 已经保证了不重复，也不会选到自己。
  5. ⑤
    撤销了什么
    path.pop_back()，然后换下一个 i。

和 39 一样用 start，区别在 收集时机：子集每个节点都收集；组合总和只在 rest == 0 时收集。和 46 的区别在于用 start 代替 used。

    
收集放在 for 前面要在 for 循环之前收集，空集 [] 也算一个。放在 if (i == n) 里只收集叶子，就漏掉了大部分子集。
下一层传 i + 1写成 dfs(start + 1) 是错的：下一层要从刚选的 i 后面开始，不是从 start 后面。
