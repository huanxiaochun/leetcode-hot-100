其实是一个排列：每行一个、每列一个，就是 0 ~ n − 1 的排列，col 数组就是 46 的 used 数组。多出来的是两条对角线的检查。

    
对角线的下标同一条 / 对角线上 r + c 相同；同一条 \ 对角线上 r − c 相同，它可能是负数，要加 n − 1 才能当下标。
三个标记一起改放下时三个数组都要标 true，撤销时三个都要改回 false，少一个后面就会误判。

  

  

    

      
时间O(n!)

      

        
第 0 行 n 种→第 1 行最多 n − 1 种→……

        
每一行的皇后不能和上面任何一个同列，所以第 r 行最多只剩 n − r 列可选，乘起来不超过 n!；对角线还会再剪掉很多。三个数组让「这里能不能放」变成 O(1) 查询。

n = 1 ~ 8 的摆法数

    

    

      
空间O(n)

      

        
col n+两条对角线各 2n − 1+递归 n 层

        
n × n 的棋盘一共有 2n − 1 条 / 对角线（r + c 从 0 到 2n − 2），\ 对角线也是 2n − 1 条（r − c 从 −(n − 1) 到 n − 1，加 n − 1 变成下标）。

      

    

    

      
对比逐格检查

      

        
不用数组的话，每放一个都要往上扫整列和两条斜线，O(n)，总共多一个 n 的因子。还可以把三个数组压成三个整数的二进制位（位运算 N 皇后），更快但更难读。
