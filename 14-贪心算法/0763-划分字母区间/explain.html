763. 划分字母区间

中等 贪心算法 LeetCode ↗

同一个字母只能出现在一个片段里，所以一个片段必须一直延伸到它里面每个字母的最后一次出现。先记下每个字母最后出现的位置 last；再从左往右扫，用 end 记「当前片段至少要延伸到哪」，扫到 i == end 时就能切一刀。

s（蓝框是当前片段已经扫过的部分，橙色虚线是它至少还要延伸到的地方；红线是切开的位置）
last：每个字母最后出现的下标

  

  

  



  

    
贪心为什么对

    
贪心 = 每一步只做眼前最好的选择，从不回头。关键是说清楚：眼前最好的选择，为什么不会错过全局最优

    
贪心选择片段一定要延伸到它里面每个字母的最后一次出现；能切就马上切
  1. 如果某个字母在片段里出现了，它所有的出现都得在这个片段里，所以片段右端至少是这些字母最后位置的最大值 end。
  2. 扫到 i == end 时，片段里的字母后面都不会再出现了，此时切就是最短的合法片段。
  3. 越早切，留给后面的字母越多，片段数只会更多不会更少：所以「能切就切」得到的片段数最多。
"abaccd"：a 最后在 2，所以第一段至少到 2；b 在 1，没超过。扫到 2 就切，再从 3 开始

  

  

    
归纳 · 同类题 · 易错点

    
贪心 · 区间合并每个字母对应一个区间 [第一次, 最后一次]，有交集的区间要合在一起

    
56合并区间
本质是同一题：每个字母看成区间 [first, last]，把重叠的区间合并，合并后的每一段就是一个片段
55跳跃游戏
同样是「右端点不断往右推」，那里推的是能到达的最远下标
45跳跃游戏 II
同样在 i 走到右边界 end 时做一次决定：那里是多跳一次，这里是切一刀

    
先预处理 last只扫一遍是不够的：扫到一个字母时，必须已经知道它后面还会不会出现。所以先单独扫一遍记最后位置
长度是 end − start + 1记得切完把 start 移到 i + 1。片段长度用两端下标相减再加 1，别漏了 +1

  
  

    

      
时间O(n)

      

        
扫两遍：记 last 一遍+划分一遍

        
每个字母的最后位置先存好，第二遍每一步只做一次取 max 和一次比较。

      

      
abaccd
