55. 跳跃游戏

中等 贪心算法 LeetCode ↗

不用关心具体怎么跳，只记一个数：far = 目前能到达的最远下标。从左往右走，每到一格就用 i + nums[i] 更新 far；如果走到的格子比 far 还远，说明这格到不了，后面也都到不了。

nums：格子里的数是从这格最多能跳几步（橙色弧线是当前格能跳到的格子，下面绿色条是 [0, far]：这些格子都到得了）

  

  

  



  

    
贪心为什么对

    
贪心 = 每一步只做眼前最好的选择，从不回头。关键是说清楚：眼前最好的选择，为什么不会错过全局最优

    
贪心选择只记能到达的最远下标 far，每到一格就用 i + nums[i] 把它往右推
  1. 能到达的格子一定是连续的一段 [0, far]：能跳到 far，就能用更小的步子跳到 far 前面的任何一格（每格的数是「最多」跳几步）。
  2. 所以不用记「哪些格子能到」，只记右端点 far 就够了。
  3. 走到某格 i 时如果 i > far，说明 [0, far] 里谁都跳不过来，i 和它后面的格子都到不了。
[3, 2, 1, 0, 4]：前三格最远都只能落到下标 3，而 3 上是 0。far 卡在 3，下标 4 永远到不了

  

  

    
归纳 · 同类题 · 易错点

    
贪心 · 区间覆盖只维护覆盖范围的右端点

同样维护 far，但要数最少跳几次：把覆盖范围分成一层一层，每层就是多跳一次

同样是「一段区间的右端点不断往右推」，推到当前位置时就切一刀
56合并区间
也是维护当前区间的右端点：下一个区间的起点 ≤ 右端点，就合并并扩大右端点

    
先判断 i > far 再更新顺序反了会用到不了的格子去更新 far。比如 [0, 1]：i = 1 时 far 还是 0，要先返回 false，不能先用 1 + 1 把 far 推到 2
只有一格的时候[0] 起点就是终点，答案是 true。i = 0 时 far = 0 ≥ n − 1 = 0，直接返回 true

  
  

    

      
时间O(n)

      

        
每格只看一次×O(1) 更新 far

        
能到达的格子是连续的一段 [0, far]，所以只要维护一个右端点，不用记每格能不能到。

      

      
23114
[2, 3, 1, 1, 4]：在下标 1 时 far 就到了 4

    

    

      
空间O(1)

      

        
只有一个变量 far

        
不需要额外数组：每格的信息用完就不再需要。

      

    

    

      
对比DP O(n²)

      

        
dp[i] = 能不能到 i：dp[i] 为真，当且仅当前面有某个能到的 j 满足 j + nums[j] ≥ i，每格往回看一遍是 O(n²)。贪心发现 dp 为真的格子总是连续一段，于是只记右端点。
