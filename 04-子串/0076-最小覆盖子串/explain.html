76. 最小覆盖子串

困难 子串 LeetCode ↗

右边扩张到覆盖 t，再从左边收缩到刚好不覆盖。过程中记下最短的那段。

s  （蓝色是窗口，加粗的是 t 里的字符，绿色下划线是目前最短）
need  每个字符还欠几个（≤ 0 表示够了）

  

  

  


  

    

      
时间O(m + n)

      

        
数 t O(n)+r 走一遍 O(m)+l 只往右 O(m)=O(m + n)

        
先扩张 r 直到覆盖，再收缩 l 直到不覆盖。l、r 都只向右走，每个字符最多进窗口一次、出窗口一次。

      

      
ADOBEC→BANC
覆盖后收缩，不覆盖再扩张

    

    

      
空间O(|Σ|)

      

        
need 计数数组 + 一个 missing

        
用 missing 记还差几个字符，判断「是否全覆盖」只要看它是不是 0，不用每次比较整张表。

      

    

    

      
对比O(m² · |Σ|)

      

        
暴力枚举所有子串再检查是否覆盖 t。滑动窗口利用了单调性：[l, r] 已经覆盖，就没必要再看更长的 [l, r+1]，直接收缩左边。
