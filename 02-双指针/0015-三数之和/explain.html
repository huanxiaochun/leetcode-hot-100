15. 三数之和

中等 双指针 LeetCode ↗

先排序，固定第一个数 nums[i]，在它右边用双指针找两数之和等于 −nums[i]。

排序后的 nums
答案

  

  

  


  

    

      
时间O(n²)

      

        
排序 O(n log n)+固定 i：n 次×双指针扫一遍 O(n)=O(n²)

        
外层枚举第一个数，里层的 l、r 只会相向移动，每轮最多 n 步，所以是 n × n。排序的 n log n 比它小，可以忽略。

      

      
il→…←r
每个 i 都在右边做一次「两数之和」

    

    

      
空间O(log n)

      

        
排序用的递归栈+指针只有 i、l、r

        
不算答案本身，额外空间只有排序的栈空间。

      

    

    

      
对比O(n³)

      

        
暴力三重循环要试所有三元组，还得额外用 set 去重。排序之后，有序性让双指针能一步排除一整列，去重也只需跳过相同的相邻数。
