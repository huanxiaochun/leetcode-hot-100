4. 寻找两个正序数组的中位数

困难 二分查找 LeetCode ↗

在两个数组上各切一刀，让左边一共 half 个数。只要 a 左最大 ≤ b 右最小 并且 b 左最大 ≤ a 右最小，就切对了。在短的数组上二分切口 i。

a（较短，橙线是切口：左边浅蓝的 i 个放进左半部分）
b（左边放 j = half − i 个）

  

  

  


  

    

      
时间O(log min(m, n))

      

        
只在短的数组上二分切口 i→j 由 half − i 直接算出

        
中位数把所有数分成个数相等的两半，左边都 ≤ 右边。两个数组各自有序，所以只要检查切口两侧的交叉那两对：aL ≤ bR、bL ≤ aR。

      

      
1389157111819
左边 5 个 + 右边：左边最大 11 ≤ 右边最小 15

    

    

      
空间O(1)

      

        
只有几个下标和 4 个边界值

        
切口在最边上时（i = 0 或 i = m），用 −∞ / +∞ 代替不存在的那个数，比较就不用特判。

      

    

    

      
对比O(m + n)

      

        
归并两个数组走到中间，最直观但是 O(m + n)。另一种 O(log(m + n)) 的做法是二分找第 k 小：每次比较两个数组的第 k/2 个，扔掉较小那边的前 k/2 个。
