912. 排序数组

中等 字节高频 LeetCode ↗

手写快速排序：在区间里随机挑一个基准 pivot，一趟三路划分成 < pivot | == pivot | > pivot 三块。中间那块已经在最终位置，只对两边递归。全是重复元素时一趟就结束。

nums（演示里的「随机」用固定种子，每次结果一样；真实代码每次随机挑）
< pivot== pivot> pivoti ~ gt 还没看已在最终位置
递归栈：正在排哪个区间 [l, r]

  

  

  


  

    
易错点

    
易错：> pivot 时 i 不能 ++nums[i] > pivot 时和 gt 处交换，换过来的是 gt 处还没检查过的数，i 必须留在原地下一轮再看。< pivot 时换过来的是已经看过的「等于」区，所以 i 可以 ++。
易错：基准要随机固定选第一个，遇到已排好序的数组会退化到 O(n²)，912 的数据会超时。

  

  

    

      
时间期望 O(n log n)

      

        
每层划分合计 O(n)×随机基准下期望 log n 层

        
每一层递归里，所有区间的划分加起来扫 n 个数。基准随机，期望每次分得比较均匀，深度 log n。最坏 O(n²)：每次都抽到最大或最小值，随机下概率极低。

三路划分：中间等于 pivot 的一块不再参与递归

    

    

      
空间期望 O(log n)

      

        
递归栈深度

        
原地交换，不需要额外数组；空间只花在递归栈上，期望 log n 层，最坏 n 层。

      

    

    

      
对比二路划分 / 固定基准

      

        
固定选第一个当基准，遇到已排好序的数组每次只分出一个数，退化成 O(n²)。二路划分遇到大量重复（如全是 2）也会退化成 O(n²)；三路划分把相等的一次性收进中间，一趟就结束。
