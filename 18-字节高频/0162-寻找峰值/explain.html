162. 寻找峰值

中等 字节高频 LeetCode ↗

没排序也能二分，靠的是往上坡走一定能到峰：nums[mid] < nums[mid+1] 说明右边在上坡，峰在右边；否则峰在左边（含 mid）。

柱子高度就是 nums[i]，两端外面看成 −∞（暗掉的已经排除，橙色是 mid + 1）

  

  

  


  

    

      
时间O(log n)

      

        
每轮扔掉一半→[lo, hi] 里始终有峰

        
不需要有序，只需要「能判断答案在哪一半」。nums[mid] < nums[mid + 1] 时，从 mid + 1 一直往右：要么某处开始下坡（那里就是峰），要么走到头碰到 −∞（最后一个就是峰）。

      

      
1213564
mid = 3：3 < 5 是上坡，右边一定有峰

    

    

      
空间O(1)

      

        
只有 lo、hi、mid

        
答案不唯一，返回任意一个峰都对。题目保证相邻元素不相等，所以不会出现平台。

      

    

    

      
易错hi = mid

      

        
循环写 lo < hi，并且 hi = mid（不是 mid − 1）：mid 本身可能就是峰，不能丢。mid + 1 不会越界，因为 lo < hi 时 mid < hi。
