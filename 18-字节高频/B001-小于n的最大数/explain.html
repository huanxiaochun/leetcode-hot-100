B001. 小于 n 的最大数

中等 字节高频 相近题 902 ↗

先把 n 减 1，「< n」就变成「≤ m」。从高位往低位照抄 m，抄不下去就往前回退，找第一个能放更小数字的位置，放「比它小的最大数字」，后面全填最大数字。

题目

给一组可用数字 digits（每个都在 1~9，可以重复使用）和正整数 n，用 digits 里的数字组成严格小于 n 的最大整数。凑不出来返回 -1。

例：digits = [1,2,4,9]，n = 2533 → 2499；digits = [1,2,4,9]，n = 2411 → 2299；digits = [2,3]，n = 2 → -1。

字节面试高频，不是力扣原题。相近题：902. 最大为 N 的数字组合。

digits（排序去重后；绿色 = 正在照抄的数字，黄色 = 回退时选中的更小数字）
m = n − 1 的每一位（绿色 = 照抄成功，黄色 = 卡住 / 回退位置）
答案（绿色 = 照抄的前缀，黄色 = 放更小的数字，蓝色 = 全填最大数字）

  

  

  


  

    
归纳 / 同类题提醒

    

      
贪心 + 回退从高位往低位贴着 m 走：前缀一样，后面才有机会继续贴着走；贴不住了就往前退，放小一点，后面全放最大。

      
回退到 j 时，s[0..j) 都在 digits 里（i 之前都照抄过），所以前缀一定拼得出来。
相近题 902. 最大为 N 的数字组合：同样按位贴着 n 走，那题数「≤ n 的有几个」，这题求「< n 的最大是谁」。

      
易错：先减 1不先减 1 的话，「每一位都相等」要单独处理（等于 n 不算），很容易漏。先变成 ≤ m，照抄到底就直接返回 m。
易错：回退不能只看卡住的那一位如 digits=[1,2,4,9]、m=2410：卡在 0，0 和 1 都没有更小的，要一直退到 4 放 2，得 2299。

    

  

  

    

      
时间O(L·k)

      

        
照抄 O(L)+回退每位扫一遍 digits O(L·k)=O(L·k)

        
L 是 n 的位数，k 是 digits 个数。照抄最多走 L 位；回退最多退 L 位，每位扫一遍 digits 找比 s[j] 小的最大数字。

      

      
24102299
m = 2410：0、1 都没有更小的，退到 4 放 2，后面填 9

    

    

      
空间O(L)

      

        
数字串 s+答案串

        
只存 m 的数字串和拼出来的答案，长度都是 L。have 是固定 10 格的表。
