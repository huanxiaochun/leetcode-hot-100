1221. 分割平衡字符串

简单 字节高频 LeetCode ↗

贪心：能切就切。balance 遇 R 加 1、遇 L 减 1，一回到 0 就说明从上一刀到这里刚好平衡，立刻切一刀。前缀平衡了，剩下的也平衡，早切不影响后面。

s（下方数字 = 读到这里时的 balance，绿竖线 = 切一刀）
切出来的每一段（追问「输出每一段」时记下 [start, i]）

  

  

  


  

    
归纳 / 同类题提醒

    

      
贪心计数前缀和回到 0 就切：早切不吃亏，因为剩下的部分也是平衡的，切开不影响后面怎么切。

      
和「括号匹配计数」一样的思路：R 当左括号、L 当右括号，balance 就是当前未配对的个数（这里可以为负）。

      
易错：追问：输出切出来的每一段在 balance 归零时记下 [start, i]，再把 start = i + 1，思路不变。
易错：balance 可以是负数L 开头时 balance 先变负，比如 "LLLLRRRR"；判断用 == 0，不要写成 <= 0。

每个字符只看一次，balance 归零就计数。
