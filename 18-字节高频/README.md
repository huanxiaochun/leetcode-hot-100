# 字节高频

字节跳动面试常考、但不在热题 100 里的题。每题三个文件，和其它分类一样：`explain.html` 是逐步动画演示和题解（思路、复杂度、易错点），`solution.cpp` / `solution.py` 是代码和本地测试。

```bash
g++ -std=c++17 -O2 solution.cpp -o /tmp/solution && /tmp/solution
python3 solution.py
```

出现次数来自 [LeetcodeTop · 字节跳动后端](https://github.com/afatcoder/LeetcodeTop/blob/master/bytedance/backend.md)（面经统计，数据较早）；按部门、时间筛选的最新数据见 [CodeTop](https://codetop.cc)。
