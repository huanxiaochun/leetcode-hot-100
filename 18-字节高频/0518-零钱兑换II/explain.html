518. 零钱兑换 II

中等 字节高频 LeetCode ↗

完全背包求方案数：dp[j] = 凑出金额 j 的组合数，dp[0] = 1（什么都不选）。外层枚举硬币，内层金额从小到大：dp[j] += dp[j − coin]。金额从小到大时 dp[j − coin] 里可能已经用过这枚硬币，这正是「每种无限个」。

每一行 = 处理完这枚硬币后的 dp[]（代码里只有一行，一行一行往下覆盖）。灰色：金额比硬币小，用不上，保持不变
用到的两格：上 = 不用这枚，左 = 再放一枚当前格

  

  

  


  

    

      
时间O(amount·k)

      

        
k 种硬币×每种扫一遍 amount 个金额

        
每格只做一次加法。dp[j − coin] 在 j 左边，从小到大扫时已经算好，而且已经算上了这枚硬币，所以同一种硬币能用任意多枚。

      

      
1122334
coins = [1, 2] 时的 dp[0..6]：dp[6] = 4，用 0 ~ 3 个 2，其余补 1

    

    

      
空间O(amount)

      

        
一行 dp amount + 1 格

        
二维写法 dp[i][j] = 前 i 种硬币凑出 j 的组合数，它只用到上一行和这一行左边，所以压成一行。中间值可能超过 int，C++ 用 unsigned long long，题目保证答案在 int 内。

      

    

    

      
易错循环顺序

      

        
外层硬币、内层金额：硬币按固定顺序加入，1+2 和 2+1 只算一次，是组合（本题）。外层金额、内层硬币：不同顺序算不同方案，是排列（377. 组合总和 IV）。例 1 反过来会得到 9。
