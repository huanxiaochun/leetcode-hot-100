88. 合并两个有序数组

简单 字节高频 LeetCode ↗

从后往前填：nums1 尾部是空位，每次把两边较大的数放到末尾 k，就不会覆盖还没比较的元素。nums2 放完就结束。

nums1  （虚线是 0 占位，绿色是已放好的位置）
nums2

  

  

  


  

    

      
时间O(m + n)

      

        
每步放好 1 个位置×最多 m + n 步

        
从前往后放会覆盖 nums1 还没比较的元素，只能先挪走；从后往前放时，写入位置 k 始终 ≥ i，不会踩到还没用的 nums1 元素。

      

      
…3000…6
3 和 6 比，6 大，放到最后一格

    

    

      
空间O(1)

      

        
原地写入 nums1 尾部的空位

        
nums2 先放完时，nums1 剩下的本来就在正确位置，直接结束；nums1 先放完时，循环会继续把 nums2 剩下的拷过去。

      

    

    

      
对比O(m + n) 空间

      

        
开新数组从前往后归并再拷回 nums1 最直观，但要额外空间。直接拼接后排序是 O((m+n) log(m+n))。

      

    

    

      
易错循环条件

      

        
循环条件只看 j >= 0 就够了。写成 i >= 0 && j >= 0 的话，nums1 先用完时 nums2 还剩一截，要在循环外补拷 nums2 剩下的部分，忘了就错（如 [4, 5, 6] 和 [1, 2, 3]）。
