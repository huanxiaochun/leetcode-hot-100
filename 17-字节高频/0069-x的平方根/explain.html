69. x 的平方根

简单 字节高频 LeetCode ↗

二分答案：找最大的 k，使 k·k ≤ x。在 [0, x] 上二分，mid² ≤ x 就记下 mid、往右试，否则往左找。


  

  

  


  

    

      
时间O(log x)

      

        
在 [0, x] 上二分→最多 32 轮

        
答案满足单调性：k 越大 k² 越大，所以「k² ≤ x」的 k 是一段前缀 0, 1, …, ans，二分找这段前缀的最后一个。

      

      
01491625
x = 15：k² ≤ 15 的 k 是 0~3，答案 3

    

    

      
空间O(1)

      

        
只有 lo、hi、mid、ans

        
也可以把右边界设成 x / 2 + 1 缩小区间，但不影响复杂度。

      

    

    

      
追问保留小数

      

        
面试常追问「保留几位小数」：改成在实数上二分固定次数（比如 100 次），每次 mid·mid ≤ x 就 lo = mid，否则 hi = mid；或者用牛顿迭代 r = (r + x / r) / 2，收敛更快。

      

    

    

      
易错溢出

      

        
mid * mid 会溢出 int：x 接近 2³¹ 时 mid 能到 10⁹，平方到 10¹⁸。要用 long long，或者改写成 mid ≤ x / mid（这时要注意 mid = 0 不能做除数）。
