146. LRU 缓存

中等 链表 LeetCode ↗

哈希表负责 O(1) 找到节点，双向链表负责 O(1) 挪动和删除：用过的挪到最后，满了删最前面（最久没用）的。

双向链表：head 后面最久没用，tail 前面最近用过（深色箭头是 next，浅色是 prev）

  

  

  


  

    

      
时间O(1)

      

        
哈希表找节点 O(1)+双向链表摘下 / 放到最后 O(1)

        
只用哈希表，找不出「最久没用」的是谁；只用链表，找某个 key 要 O(n)。两个搭配：哈希表存 key → 节点，节点有 prev、next，摘下自己不用从头找前一个。

      

      
head⇄2⇄1⇄tail
get(1) 后 1 挪到最后；满了就删 head 后面的 2

    

    

      
空间O(capacity)

      

        
最多 capacity 个节点 + 同样多的哈希表项

        
head、tail 两个哨兵让链表永远不为空，摘下、插入都不用判断是不是第一个或最后一个。

      

    

    

      
对比OrderedDict

      

        
Python 的 OrderedDict 内部就是哈希表 + 双向链表：move_to_end 挪到最后，popitem(last=False) 删最前面。C++ 也可以用 std::list + splice 代替手写链表。
