公司
HOGI.AI（香港）

2025-11 内测，2026-07 在美国正式上线
形态
网页，对话 + 画布
主要用户
内容创作者、游戏工作室、品牌营销、教育
一句话记住：Runway、可灵这类工具一次出一段 4~10 秒的镜头；OiiOii 让多个 Agent 共享一张「场景图」，所以角色、场景、画风在整部片子里保持一致。

7 个 Agent 怎么分工

1
美术总监
定整体视觉：画风、色板、光影、画幅。还负责给每个镜头挑底层模型
2
编剧
把一句话扩成剧本：场景列表、角色节拍、台词、旁白。用户自带剧本时，解析成同一种内部结构
3
角色设计师
锁定角色的脸型、服装、比例、发型，出多角度、多表情的角色表
4
场景设计师
做可复用的场景：森林、教室、飞船内部，带时间、天气、氛围、关键道具
5
动画师
把分镜变成视频：调用选好的模型，传入角色、场景和动作描述；保证镜头间动作连贯
6
剪辑师
排时间线、转场、按剧本控制节奏；剪辑不破坏原素材
7
音效师
按情绪起伏配乐，按画面配音效；混音、台词出现时压低音乐
所有 Agent 读写同一份场景图（剧本、角色、场景、分镜的结构化数据），这是它保持一致的关键。改剧本时，场景图更新，下游 Agent 跟着重排。

关键机制

👤

角色一致性

AI 视频最常见的问题是「换个镜头脸就变了」。角色一旦锁定，特征作为约束传给每一个有这个角色的镜头。

🎛

每镜选模型

底层接了 25 个以上模型（Sora 2、Veo 3.1、Seedance、可灵、海螺、Vidu、Midjourney 等）。不同镜头按画风和动作类型选最合适的。

🖌

画布单镜重做

不满意某个镜头，在画布上只重新生成这一个，角色、场景和故事线不动，剪辑师自动重排时间线。

♫

音乐驱动的 MV

听整首歌，分析结构、情绪、节奏和歌词，再按段落生成画面，切镜对齐节拍。

能力说明
时长15 秒的短片到 60 秒以上的叙事片
画风150 种以上：日漫、3D、电影感、水彩、水墨、像素等
输入一句话就能开始；也能带剧本、角色参考图、场景参考、配音、音乐
输出MP4 成片；角色表、场景图可以单独导出

优势与不足

✓

门槛最低

不需要会分镜和动画，用户像导演一样在对话里提要求，Agent 团队自己跑完。

✓

多镜头一致

共享场景图 + 角色锁定，解决单模型工具每次重新决定画风、脸型的问题。

✓

不绑定模型

新模型出来就能接，比如 Seedance 2.5 发布后很快上线。

!

控制力弱于画布工具

自动化程度高，专业团队想精确控制每一步时，不如 LibTV 这种人主导的画布。

!

成本和等待

多镜头、带配乐的项目要调很多次视频模型，耗时和额度消耗都明显高于单个镜头。

!

同样依赖外部模型

效果上限由底层模型决定，自己的价值在编排和一致性。

常见问题

Q1为什么要拆成 7 个 Agent，一个 Agent 不行吗？
参考答案
  • 对应真实工种：动画工作室本来就这样分工，每个 Agent 的提示词和工具更专，出错范围也小
  • 上下文隔离：角色设计不需要看到配乐细节，各自只拿需要的部分
  • 关键是共享状态：拆开之后靠同一份场景图协作，否则就会各说各话
  • 代价：协调成本和 token 开销更高，流程也更固定
Q2多镜头的角色一致性怎么做？
参考答案
  • 先定角色：出多角度、多表情的角色表，把脸型、服装、比例存成固定特征
  • 每镜都带上：生成有这个角色的镜头时，把角色表作为参考传给视频模型
  • 场景同理：场景也存成资产，换机位重拍时光影、道具不漂移
Q3OiiOii 和 LibTV 的路线差在哪？
参考答案
  • OiiOii 偏自动：Agent 团队替你跑完，适合不会做动画的个人创作者
  • LibTV 偏可控：人在画布上主导每一步，适合要精确控制的专业团队
  • 共同点：都不做底座模型，都在多家视频模型之上做编排
