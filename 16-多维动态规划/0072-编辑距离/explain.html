dp[i][j] = 把 word1 前 i 个字符变成 word2 前 j 个字符的最少步数。只看两个前缀的最后一个字符：相同就不用动（左上）；不同就三选一：替换（左上）、删除（上）、插入（左），取最少再 + 1。

行是 word1 的前 i 个字符，列是 word2 的前 j 个字符；∅ 是空串

解题五步

    
动态规划的题都可以按这五步想清楚，写代码前先在纸上把这五项填出来

    

      1
      
状态定义
dp[i][j] = 把 word1 的前 i 个字符变成 word2 的前 j 个字符，最少要几步（插入、删除、替换各算 1 步）。

      
dp[3][2]："hor" 变成 "ro" 最少几步

    

    

      2
      
转移方程
只看两个前缀的最后一个字符。相同：不用动，等于左上。不同：三种做法选最少的，再 + 1：
替换成对方的字符 → 左上；删除 word1 的最后一个 → 上；插入 word2 的最后一个 → 左。
相同：dp[i][j] = dp[i−1][j−1]
不同：dp[i][j] = 1 + min(左上, 上, 左)

      
左上 = 替换　上 = 删除　左 = 插入

    

    

      3
      
初始化 / 边界
第 0 列 dp[i][0] = i：前 i 个字符变成空串，只能全删掉。第 0 行 dp[0][j] = j：空串变成前 j 个字符，只能一个个插入。

      
边界不是 0，而是 i、j

    

    

      4
      
遍历顺序
和 1143 一样依赖左上、上、左：i 从 1 到 m，j 从 1 到 n。

      
灰色是边界值，圈号是填写顺序

    

    

      5
      
答案在哪
右下角 dp[m][n]。想知道具体怎么改，从右下角往回看每一格是从哪个方向来的：左上 = 替换（或不动），上 = 删除，左 = 插入。

      
"ab" → "cb"：把 a 替换成 c，1 步

    

  

  

    
表是怎么压成一维的

    
和 1143 一样要用左上。另外每一行的 dp[0] 要从 i − 1 变成 i，变之前它正好是下一格要用的左上

    

      
二维表：算 (i, j) 要用左上、上、左三格

      
只留一行：格子 j−1 已经改成新值（左），原来的左上没了，所以提前存进变量 prev

    

    
    
      
  • 上 = 还没改的 dp[j]；左 = 刚改完的 dp[j−1]。这两个直接能拿到。
    • 
      
  • 左上 = 改之前的 dp[j−1]。可是算 j−1 那一格时已经把它覆盖了，所以改每一格之前先用 tmp 存下旧值，算完交给下一格当 prev（左上）。
    • 
    

    
C++vector<int> dp(n + 1);
for (int j = 0; j <= n; ++j) dp[j] = j;
for (int i = 1; i <= m; ++i) {
    int prev = dp[0];              // 左上 dp[i-1][0]
    dp[0] = i;
    for (int j = 1; j <= n; ++j) {
        int tmp = dp[j];           // 先存旧值：下一格的左上
        if (a[i - 1] == b[j - 1]) dp[j] = prev;
        else dp[j] = 1 + min({prev, dp[j], dp[j - 1]});
        prev = tmp;
    }
}
return dp[n];
Pythondp = list(range(n + 1))
for i in range(1, m + 1):
    prev, dp[0] = dp[0], i         # 左上 dp[i-1][0]
    for j in range(1, n + 1):
        tmp = dp[j]                # 先存旧值：下一格的左上
        if a[i - 1] == b[j - 1]:
            dp[j] = prev
        else:
            dp[j] = 1 + min(prev, dp[j], dp[j - 1])
        prev = tmp
return dp[n]

  

  

    
归纳 / 同类题提醒

    

      
两个字符串 DP
怎么认出来：两个字符串，问把一个变成另一个最少要几步。
套路：和 1143 同一张表、同一个遍历顺序，只看最后一个字符相同 / 不同。
和 1143 的区别：边界是 i、j（不是 0）；相同时不加；不同时有三个来源（多了左上 = 替换），取 min。

易错：三个方向记反上 = dp[i−1][j]：word1 少用了一个字符，也就是删掉 word1 的最后一个；左 = dp[i][j−1]：word2 少一个，也就是插入它。
易错：相同时别再 +1最后一个字符一样就直接等于左上，不要再 + 1，也不要和上、左比 min（结果一样但容易写错成 1 + min）。

  
  

    

      
时间O(m·n)

      

        
(m+1) × (n+1) 个格子×每格看 3 个来源

        
只考虑两个前缀的最后一个字符：相同就不用动（左上）；不同就三选一：替换它（左上 + 1）、删掉 word1 的它（上面 + 1）、插入 word2 的它（左边 + 1）。

      

      
horse
rorse
ros
horse → rorse（替换 h）→ rose（删 r）→ ros（删 e），3 步

    

    

      
空间O(m·n)

      

        
二维表 dp[m+1][n+1]

        
第 0 列 dp[i][0] = i（删光），第 0 行 dp[0][j] = j（一个个插入），是整张表的起点。多开的这一行一列让转移时不用判断越界。

      

    

    

      
对比一维 O(n)

      

        
和最长公共子序列一样，每格只看上、左、左上，能压成一行，用一个变量存住左上角。不用 DP 的话要搜索所有改法，是指数级的。
