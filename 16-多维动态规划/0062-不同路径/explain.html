62. 不同路径

中等 多维动态规划 LeetCode ↗

dp[i][j] = 从左上角走到第 i 行第 j 列有几种走法。最后一步不是从上面下来就是从左边过来，所以 dp[i][j] = 上 + 左。算一行只用到上一行，代码里只存一行。

网格：🤖 每次只能往右或往下走一格，走到 🏁。格子里的数 = 走到这格有几种走法
代码里只存一行 dp[]：左边已经是这一行的新值，当前格改之前还是上一行的值（= 上面那格）
这一行已经算好还是上一行的值这次用到的格子

  

  

  



  

    
解题五步

    
动态规划的题都可以按这五步想清楚，写代码前先在纸上把这五项填出来

    

      1
      
状态定义
dp[i][j] = 从左上角 (0, 0) 走到第 i 行第 j 列，一共有几种不同的走法。

      
每一格存一个数：走到这里的走法数

    

    

      2
      
转移方程
机器人只能往右、往下。到 (i, j) 的最后一步只有两种：从上面下来，或从左边过来。两类走法不重复，所以相加。
dp[i][j] = dp[i−1][j] + dp[i][j−1]

      
当前格 = 上 + 左

    

    

      3
      
初始化 / 边界
第 0 行：只能一直往右，只有 1 种走法；第 0 列：只能一直往下，也只有 1 种。它们没有「上」或没有「左」，不能套公式，要先填好。

      
灰色边界全是 1

    

    

      4
      
遍历顺序
依赖的是上和左：所以一行一行从上往下、每行从左往右填。轮到某一格时，它上面和左边一定已经填好。

      
圈号是填写的先后顺序

    

    

      5
      
答案在哪
终点在右下角：dp[m−1][n−1]。一维写法里就是最后一行算完后的 dp[n−1]。

      
3 × 3：答案 6

    

  

  

    
表是怎么压成一维的

    
算第 i 行只用到第 i−1 行，所以没必要存整张表，一行数组从上往下「滚」就行

    

      
二维表：算 (i, j) 只用到上面一格和左边一格

      
只留一行：dp[j] 现在还是上一行的值（上），dp[j−1] 刚改成这一行的值（左）

    

    
    
      
  • 从左往右改：j 左边的已经是这一行的新值（= 左），j 和右边还是上一行的旧值（= 上）。
    • 
      
  • 所以 dp[j] = dp[j] + dp[j−1] 里，右边的 dp[j] 就是「上」，dp[j−1] 就是「左」。不用左上，所以不需要额外变量。

易错：边界不是 0第 0 行、第 0 列都是 1 种走法。初始化成 0，整张表就全是 0。
易错：m、n 别弄反m 是行数、n 是列数。一维 dp 的长度是 n（一行有几格），外层循环跑 m − 1 次。

  
  

    

      
时间O(m·n)

      

        
m × n 个格子×每格 1 次加法

        
按行从上往下、每行从左往右填。算到 (i, j) 时，上面和左边一定已经算好了，直接相加。每个格子只算一次。

空间O(n)

      

        
只留一行 dp[n]

        
算第 i 行只用到上一行和这一行左边。所以一行数组反复覆盖：dp[j] 改之前存的是上面那格，dp[j−1] 刚改完就是左边那格。

      

    

    

      
对比O(min(m, n))

      

        
用组合数直接算：不管怎么走，一共要往下 m−1 步、往右 n−1 步。答案就是在 m+n−2 步里挑哪 m−1 步往下：C(m+n−2, m−1)。比如 3 × 7：C(8, 2) = 28。
