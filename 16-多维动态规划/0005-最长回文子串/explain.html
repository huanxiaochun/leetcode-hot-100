5. 最长回文子串

中等 多维动态规划 LeetCode ↗

dp[i][j] = s[i..j] 是不是回文。它是回文 ⇔ 两头 s[i] == s[j]，并且去掉两头后的 s[i+1..j−1] 也是回文。所以 dp[i][j] 依赖它左下方的 dp[i+1][j−1]。

s（蓝框是两头 i、j；橙色下划线是要查的中间；绿色下划线是目前最长的回文）
dp[i][j]：s[i..j] 是不是回文。行是 i，列是 j，只用右上半张，从最下面一行往上填
✓ 是回文✗ 不是用到的中间那段目前最长

  

  

  



  

    
解题五步

    
动态规划的题都可以按这五步想清楚，写代码前先在纸上把这五项填出来

    

      1
      
状态定义
dp[i][j] = 子串 s[i..j]（从下标 i 到 j，两头都包含）是不是回文，存 true / false。

      
dp[1][3] 问的是 "aba" 是不是回文

    

    

      2
      
转移方程
回文去掉两头还是回文。所以 s[i..j] 是回文 ⇔ 两头相等，并且中间 s[i+1..j−1] 也是回文。中间那段在表里是当前格的左下方。
dp[i][j] = (s[i] == s[j]) && dp[i+1][j−1]

      
依赖左下方那一格

    

    

      3
      
初始化 / 边界
长度 1：一个字符本身就是回文，对角线全是 ✓。长度 2：没有「中间」，只看两头。代码里用 j − i < 2 合并处理这两种情况。左下半张（j < i）没有意义，用不到。

      
对角线 = 长度 1

    

    

      4
      
遍历顺序
dp[i][j] 要用下一行的 dp[i+1][j−1]，所以 i 必须从大到小（从最下面一行往上填）；同一行里 j 从小到大。
如果 i 从小到大，算第 0 行时第 1 行还是空的，就会读到没算的值。也可以按长度从短到长填，同样保证中间那段先算好。

      
数字是填写顺序：第 10 个 dp[1][4] 要用的 dp[2][3] 是第 5 个，早就填好了

    

    

      5
      
答案在哪
答案不是某一个固定的格子：所有 ✓ 里 j − i + 1 最大的那个。边填表边记下起点 start 和长度 len，最后返回 s.substr(start, len)。

      
"babad"：最长的 ✓ 是 "aba"（"bab" 一样长）

    

  

  

    
归纳 / 同类题提醒

    

      
区间 DP
怎么认出来：问的是一段连续区间 [i, j] 的性质，并且大区间的答案能由去掉两头后的小区间推出来。
和本模块其他题的区别：62 / 64 / 1143 / 72 的 dp[i][j] 都是「前 i 个、前 j 个」（前缀），依赖上、左；这题的 dp[i][j] 是「从 i 到 j 这一段」，依赖左下方，所以遍历顺序也不一样。
子串 vs 子序列：这题要连续（子串）；516「最长回文子序列」不要求连续，转移会变成 max(dp[i+1][j], dp[i][j−1])。

      
本模块里同一个套路的题
题模型dp 表示转移
62 不同路径网格路径走到 (i, j) 的走法数上 + 左
64 最小路径和网格路径走到 (i, j) 的最小和min(上, 左) + 这格
1143 最长公共子序列两个字符串两个前缀的 LCS 长度相同：左上 + 1；不同：max(上, 左)
72 编辑距离两个字符串前缀变前缀的最少步数相同：左上；不同：1 + min(三个)
5 最长回文子串区间 DPs[i..j] 是不是回文两头相等 且 左下方 ✓

    

    
易错：遍历顺序写反i 从 0 开始往上数，会读到还没算的 dp[i+1][..]。一定从 n − 1 往 0 走，或者按长度从短到长。
易错：短串的特判长度 1、2 时 i + 1 > j − 1，中间是空的。不先判 j − i < 2 就会访问到左下半张，得到错误的 false。

  
  

    

      
时间O(n²)

      

        
n(n+1)/2 个子串×每个 O(1) 判断

        
s[i..j] 是回文 ⇔ 两头相等，并且中间 s[i+1..j−1] 也是回文。中间那段更短、已经存在表里，不用再从头比一遍。

      

      
cabbac
两头 c = c，中间 abba 已知是回文 → cabbac 也是

    

    

      
空间O(n²)

      

        
n × n 的 bool 表，只用右上半张

        
dp[i][j] 用到的是下一行的 dp[i+1][j−1]，所以 i 要从大到小算；同一行里 j 从小到大。长度 ≤ 2 的子串没有「中间」，直接看两头。

      

    

    

      
对比中心扩展

      

        
枚举 2n−1 个中心（每个字符、每两个字符之间），向两边扩到不相等为止：时间同样 O(n²)，空间 O(1)，写题更常用。Manacher 算法能做到 O(n)，面试很少要求。暴力枚举所有子串再逐个判断是 O(n³)。
