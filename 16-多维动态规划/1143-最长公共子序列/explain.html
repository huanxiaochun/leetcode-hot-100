1143. 最长公共子序列

中等 多维动态规划 LeetCode ↗

dp[i][j] = text1 前 i 个字符和 text2 前 j 个字符的最长公共子序列长度。只看两个前缀的最后一个字符：相同就配成一对（左上 + 1）；不同就扔掉其中一个（上面或左边取大的）。

行是 text1 的前 i 个字符，列是 text2 的前 j 个字符；∅ 是空串。表头里蓝色 / 橙色是正在比的两个字符
用到的格子比较后没选的回溯路线配上的一对

  

  

  



  

    
解题五步

    
动态规划的题都可以按这五步想清楚，写代码前先在纸上把这五项填出来

    

      1
      
状态定义
dp[i][j] = text1 的前 i 个字符和 text2 的前 j 个字符，最长公共子序列有多长。i、j 是「个数」，对应的字符是 text1[i−1]、text2[j−1]。

      
dp[3][2]：比的是 "abc" 和 "ac"

    

    

      2
      
转移方程
只看两个前缀的最后一个字符：
相同：这一对一定可以配上，前面的部分看左上，再 + 1。
不同：它俩不可能都用上，扔掉 text1 的最后一个（看上）或扔掉 text2 的最后一个（看左），取大的。
相同：dp[i][j] = dp[i−1][j−1] + 1
不同：dp[i][j] = max(dp[i−1][j], dp[i][j−1])

      
左上：配一对 +1　上 / 左：扔掉一个

    

    

      3
      
初始化 / 边界
多开第 0 行、第 0 列表示空串。空串和任何串的公共子序列都是空的，所以全是 0。这样 i − 1、j − 1 永远不会越界。

      
∅ 那一行一列全是 0

    

    

      4
      
遍历顺序
依赖左上、上、左，它们都在当前格的「前面」：i 从 1 到 m，j 从 1 到 n，一行一行填。

      
圈号是填写顺序

    

    

      5
      
答案在哪
两个完整的串：右下角 dp[m][n]。要具体的子序列，就从右下角往回：字符相同走左上并记下这个字符，不同就退到上、左里较大的那格。

      
"abc" 和 "ac"：答案 2

    

  

  

    
表是怎么压成一维的

    
每行只用到上一行和这一行左边，可以只留一行。但这题还要用左上，它会被提前覆盖，要先存下来

    

      
二维表：算 (i, j) 要用左上、上、左三格

      
只留一行：格子 j−1 已经改成新值（左），原来的左上没了，所以提前存进变量 prev

    

    
    
      
  • 上 = 还没改的 dp[j]；左 = 刚改完的 dp[j−1]。这两个直接能拿到。
    • 
      
  • 左上 = 改之前的 dp[j−1]。可是算 j−1 那一格时已经把它覆盖了，所以改每一格之前先用 tmp 存下旧值，算完交给下一格当 prev（左上）。
    • 
    

    
C++vector<int> dp(n + 1, 0);
for (int i = 1; i <= m; ++i) {
    int prev = 0;                  // 左上 dp[i-1][0]
    for (int j = 1; j <= n; ++j) {
        int tmp = dp[j];           // 先存旧值：下一格的左上
        if (a[i - 1] == b[j - 1]) dp[j] = prev + 1;
        else dp[j] = max(dp[j], dp[j - 1]);
        prev = tmp;
    }
}
return dp[n];

归纳 / 同类题提醒

    

      
两个字符串 DP
怎么认出来：给两个字符串（或数组），问它们之间的某种匹配：公共部分多长、要改几步才一样……
套路：开 (m+1) × (n+1) 的表，dp[i][j] 管「两个前缀」，只看两个前缀的最后一个字符：相同怎么办、不同怎么办。依赖左上、上、左。
和 72 的区别：表的形状、遍历顺序完全一样。1143 求最长（相同 +1，取 max），边界是 0；72 求最少步数（相同不加，不同三选一 +1，取 min），边界是 i、j。

      
本模块里同一个套路的题
题模型dp 表示转移
62 不同路径网格路径走到 (i, j) 的走法数上 + 左
64 最小路径和网格路径走到 (i, j) 的最小和min(上, 左) + 这格
1143 最长公共子序列两个字符串两个前缀的 LCS 长度相同：左上 + 1；不同：max(上, 左)
72 编辑距离两个字符串前缀变前缀的最少步数相同：左上；不同：1 + min(三个)
5 最长回文子串区间 DPs[i..j] 是不是回文两头相等 且 左下方 ✓

    

    
易错：下标差 1dp[i][j] 对应的字符是 text1[i − 1]、text2[j − 1]。写成 text1[i] 会错位，最后一个字符也会越界。
易错：子序列不用连续不同的时候是 max(上, 左)，不是直接变 0。变 0 是「最长公共子串」（要求连续）的写法。

  
  

    

      
时间O(m·n)

      

        
(m+1) × (n+1) 个格子×每格 O(1)

        
看两个前缀的最后一个字符：一样就一起配上（左上 + 1）；不一样就至少有一个用不上，扔掉 text1 的（上面）或扔掉 text2 的（左边），取大的。每个格子只算一次。

abcde 和 ace：LCS = ace，长度 3

    

    

      
空间O(m·n)

      

        
二维表 dp[m+1][n+1]

        
多开一行一列表示空串，dp[0][*] = dp[*][0] = 0。这样转移时不用判断 i−1、j−1 越界。表里 dp[i][j] 对应的字符是 text1[i−1]、text2[j−1]。

      

    

    

      
对比一维 O(n)

      

        
每行只用到上一行和这一行左边，可以压成一行；但左上角 dp[i−1][j−1] 会先被覆盖，要用一个变量提前存下来。暴力枚举 text1 的所有子序列再去 text2 里找，是 O(2^m · n)。
