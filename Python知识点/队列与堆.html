易错点

空栈 st[-1] / st.pop()IndexError，先判 if st:
st.pop(0)这是从栈底删，O(n)；栈只用 pop()
while a[st[-1]] < x and st条件从左往右算，空栈先访问就报错；st 放前面

Python 队列与堆 · 03

deque

双端队列：两头都能 O(1) 进出两端 O(1)

易错点

list.pop(0) 当队列每次 O(n)，BFS 会超时；用 deque.popleft()
dq[i] 访问中间中间下标是 O(n)，deque 只适合看两头
for _ in range(len(q))range 在开始时就算好了次数，循环里 append 不影响；这是正确的按层写法
deque(3)参数要是可迭代对象，TypeError；限长写 deque(maxlen=3)

Python 队列与堆 · 04

heapq

小顶堆：h[0] 永远是最小值O(log n)

易错点

以为 heapq 是大顶堆heapq 只有小顶堆；要最大值就存负数
h = heapq.heapify(a)heapify 原地修改、返回 None；直接写 heapq.heapify(a)
h[1] 当成第二小堆只保证 h[0] 最小，h[1]、h[2] 谁小不一定；第二小要 pop 一次
sorted(h) 当堆用每次排序 O(n log n)；用 heappush / heappop

Python 队列与堆 · 05

组合用法

堆里放 tuple：按第一个元素比较

易错点

heappush(h, (p, node))p 相同时会去比 node，对象不能比较就 TypeError；中间加下标或计数器
大顶堆忘了取反回来取出来是负数；用的时候写 -h[0][0]
想删堆中间的元素heapq 不支持；延迟删除：堆顶过期时再弹
tuple 里放 listlist 能比较但很慢，还可能比较到可变内容；只放数字或下标
