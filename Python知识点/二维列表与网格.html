Python 二维列表与网格 · 02

创建与拷贝

m 行 n 列：每行必须是不同的 list下标 O(1)

易错点

[[0] * n] * mm 行共用一个 list，改一处全变；写 [[0] * n for _ in range(m)]
b = a[:]只拷了外层，每行还是同一个；写 [row[:] for row in a]
g[j][i] 写反第一个下标是行、第二个是列；i 配 m、j 配 n
空矩阵 len(g[0])g 为空时 IndexError；可能为空就先判 if not g

Python 二维列表与网格 · 03

遍历与判断

for row in g，配合 any / all / sumO(mn)

易错点

for x in row: x = 0x 只是变量，赋值改不到列表；要写 row[j] = 0
any([... for ...])方括号会先算完整个列表；写成圆括号的生成器，找到就停
max(g)比较的是整行（字典序），得到一行；全局最大写 max(map(max, g))
边遍历边置 0新置的 0 会被当成原来的 0 继续扩散；先记录，再统一修改

Python 二维列表与网格 · 04

zip(*g)

转置、旋转：zip 把每一列打包成一行O(mn)

易错点

zip(*g) 的结果是 tuple每一项是 tuple，不能改；要列表写 [list(c) for c in zip(*g)]
g = [... zip ...]函数里重新赋值，调用方的矩阵没变；原地改写 g[:] = ...
行长度不一样zip 按最短的那行截断，会丢数据；先确认每行一样长
转置时 j 从 0 开始每对会被交换两次，等于没换；j 从 i + 1 开始

方向与边界

上下左右四个邻居，先判越界再访问

易错点

g[-1][0] 不报错负下标会取到最后一行，越界不报错，只能自己判断 0 <= x
x < m and g[x][y]短路求值：越界判断必须写在前面
seen.add([x, y])list 不可哈希，TypeError；坐标用 (x, y)
DIRS 顺序乱写螺旋、右转依赖顺序；按顺时针写，右转就是 d + 1
