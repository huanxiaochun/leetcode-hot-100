怎么选

    
点一行切换到那个算法。稳定：相同的数排完以后先后顺序不变（选「有重复」那组数据看角标 a、b）

    

      
算法平均最坏额外空间稳定性什么时候用

      
冒泡排序O(n²)O(n²)O(1)稳定几乎有序时一轮就能结束；实际很少用
选择排序O(n²)O(n²)O(1)不稳定交换次数最少（最多 n − 1 次），但比较次数固定 n²/2
插入排序O(n²)O(n²)O(1)稳定数据几乎有序或很少时最快；sorted() 用的 Timsort 里，短的段就用它
归并排序O(n log n)O(n log n)O(n)稳定时间稳定在 n log n，要额外数组；Timsort 也是归并的思路，所以 sorted() 是稳定的
快速排序O(n log n)O(n²)O(log n)不稳定平均最快；有序数组 + 选最后一个当基准会退化，所以要随机选基准
堆排序O(n log n)O(n log n)O(1)不稳定最坏也是 n log n 且不占额外空间；heapq 用的就是堆

    

    
实际写题直接用 sorted() 或 list.sort()（Timsort：归并 + 插入的混合，最坏 O(n log n)，稳定）；只要最小的 k 个可以用 heapq.nsmallest(k, a)。
