三种顺序，只差在「什么时候访问根」

    
从根的左边出发，沿着树的外轮廓绕一圈（虚线）。每个节点会被经过 3 次：左边、下边、右边。
      在左边记下来就是前序，在下边记下来是中序，在右边记下来是后序。递归代码里，这三个时刻正好对应「进入函数时」「左子树返回后」「右子树返回后」。

    

      

      

    

  


  

    
怎么记、什么时候用

    
点一行切换到那种遍历。四种遍历的时间都是 O(n)；递归和栈的空间是 O(h)（h 是树高，最坏等于 n），层序的队列是 O(w)（w 是最宽那一层的节点数）。

    

      
遍历顺序迭代用迭代写法的关键典型题

      
前序根 左 右栈弹出就访问；先压右、再压左，左孩子先出栈复制一棵树、序列化；114 展开为链表、105 从前序建树
中序左 根 右栈 + cur一路往左压栈，弹出时访问，再转到右子树二叉搜索树的中序是升序：94、98 验证 BST、230 第 K 小
后序左 右 根栈 + prev看栈顶不急着弹：右子树没走过就先走右边，走过了才访问要先拿到孩子的结果再算自己：104 深度、543 直径、124 路径和、236 公共祖先
层序一层一层队列从队头取、孩子放队尾；按层分组时先记下这一层有几个102 层序遍历、199 右视图；求最少步数的 BFS

    

    
后序还有一种好记的迭代写法：按「根 → 右 → 左」做前序（先压左、再压右），最后把结果整个反转，就是「左 → 右 → 根」。Python 默认递归深度上限是 1000（sys.getrecursionlimit()）。树可能很深时，用 sys.setrecursionlimit 调大，或者直接用迭代写法。
