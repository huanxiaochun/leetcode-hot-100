四步法：从暴力递归到 DP

易错点

dp[i] 说不清是什么转移一定写不对。先写一句话：dp[i] = …
@cache 的参数是 listlist 不能哈希会报 TypeError；参数用下标或 tuple
记忆化递归太深默认递归上限 1000；n 很大时改成递推
先写滚动变量容易写乱；先写出完整的表，对了再压缩

Python 动态规划 · 03

线性 DP：「以 i 结尾」和「前 i 个」

状态只有一个下标：dp[i] 由它前面几个格子算出来O(n) ~ O(n²)

易错点

以 i 结尾的答案取 dp[-1]最优的不一定以最后一个结尾，答案是 max(dp)
乘积只记最大值遇到负数，原来最小的会变成最大的；max 和 min 都要
mx = ...; mn = ... 分两行第二行用到的是新的 mx；用同时赋值或先存临时变量
单词表用 list 查in list 是 O(n)；先转成 set

Python 动态规划 · 04

背包：容量当下标

每个物品选或不选，dp[j] = 容量 j 时的最优值 / 能否凑出 / 方案数O(n × 容量)

易错点

0/1 背包正序遍历同一个物品会被用多次，变成了完全背包
range(target, x, -1)range 不含终点，j = x 那一格漏了；写 x - 1
dp[0] 没设整张表都是初始值，什么都推不出来；凑出 0 是不选
方案数里外层循环的顺序外层物品：组合数（不计顺序）；外层容量：排列数

Python 动态规划 · 05

二维 DP：网格和两个字符串

dp[i][j] 由左边、上边、左上三个格子算出来O(m × n)

易错点

[[0] * n] * mm 行是同一个 list，改一格整列都变；用列表推导
a[i] 和 dp[i] 对不上dp 多了一行，dp[i][j] 比较的是 a[i-1] 和 b[j-1]
编辑距离边界填 0空串变成长度 i 的串要 i 步：dp[i][0] = i，dp[0][j] = j
压成一维后丢了左上角左上 dp[i-1][j-1] 会被覆盖，要先用变量存下来

Python 动态规划 · 06

区间 DP 与遍历顺序

「按什么顺序填表」由依赖关系决定：用到的格子必须先算好O(n²)

易错点

回文 dp 的 i 从小到大dp[i+1][j-1] 还没算，读到的是初始值
j - i < 2 没特判长度 1、2 的区间，dp[i+1][j-1] 是空区间或者越界
dp[i - 2] 当 i = 1负下标不报错，会读到表的最后一格；先判断 i ≥ 2
区间问题只开一维「一段」需要左右两个端点，状态至少是 dp[i][j]

Python 动态规划 · 07

图解：DP 为什么快

同一个子问题，递归会算很多遍；DP 只算一遍并记下来

暴力递归爬楼梯 f(n) = f(n−1) + f(n−2)

f(3) 算了 2 遍，f(2) 算了 3 遍。n 每加 1，递归树就大一倍：O(2ⁿ)

填表从小到大，每格只算一次

算 dp[5] 时，dp[4]、dp[3] 早就在表里了，直接拿来用：O(n)。这就是「重复子问题」：有它才值得用 DP

记住

能用 DP 的信号大问题的答案能由更小的同类问题拼出来
还要有重复子问题会被反复用到，记下来才省时间
自顶向下递归 + 备忘录：哪个子问题没算过就去算
自底向上按依赖顺序填表，没有递归开销，还能压缩空间

Python 动态规划 · 08

图解：填表顺序跟着箭头走

当前格用到的格子（橙色）必须先算好，循环方向就由箭头决定

二维：左、上、左上LCS、编辑距离

箭头都从上面或左边来：一行一行往下、每行从左往右填

区间：左下方最长回文子串

用到的是下一行（左下方）：i 要从大到小，从下往上一行行填；左下角那半张表没用

0/1 背包：为什么倒序放入数字 2

正序时 dp[4] 用的 dp[2] 是刚被 2 改过的，等于 2 用了两次；倒序用的都是上一轮的值

记住

先画箭头再写循环把 dp[…] 用到的格子都画出来，循环方向顺着箭头
用到 i − 1i 从小到大
用到 i + 1i 从大到小
一维数组省空间覆盖前还要读的旧值，要么倒序，要么先存到变量里

Python 动态规划 · 09

五步法：每道 DP 题都问这五个问题

写代码之前，先把这一张表填出来
题① 状态定义② 转移：看最后一步③ 初始化④ 顺序⑤ 答案
爬楼梯dp[i] = 走到第 i 阶的方法数最后一步走 1 或 2 阶
dp[i−1] + dp[i−2]		dp[1] = 1, dp[2] = 2i 从小到大dp[n]
打家劫舍dp[i] = 前 i 间最多偷多少第 i 间偷：dp[i−2] + a[i]
不偷：dp[i−1]，取大的		一间都没有时是 0i 从小到大dp[n]
零钱兑换dp[j] = 凑出 j 最少几枚最后一枚是哪种硬币
min(dp[j − c] + 1)		dp[0] = 0，其余inf（凑不出）j 从小到大（完全背包）dp[amount]，没变就是 −1
最长递增子序列dp[i] = 以 a[i] 结尾的最长长度接在前面哪个更小的数后面
max(dp[j] + 1)		每个数自己就是 1i 从小到大max(dp)，不是最后一格
最长公共子序列dp[i][j] = a 前 i 个、b 前 j 个的答案最后两个字符相等：左上 + 1
不等：max(上, 左)		空串那一行、一列都是 0i、j 都从小到大dp[m][n]

① 最难：定义写成一句完整的话。② 转移：只看最后一步有几种可能。③ 初始化：最小的状态直接写；求最小值时其余设成「不可能」。⑤ 答案：「以 i 结尾」要在所有 dp[i] 里取最大
