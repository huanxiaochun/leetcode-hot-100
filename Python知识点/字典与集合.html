Python 字典与集合 · 02

dict

字典：键 → 值，按插入顺序平均 O(1)

易错点

d[k] += 1k 不存在会 KeyError，写 d[k] = d.get(k, 0) + 1
遍历时增删键RuntimeError，遍历副本 for k in list(d)
x in d.values()查的是值，O(n)；x in d 查键才是 O(1)
d = {}这是空 dict，空集合要写 set()

Python 字典与集合 · 03

set

集合：只存键，自动去重平均 O(1)

易错点

s = {}得到的是空 dict，空集合用 set()
s[0]集合没有顺序，不能下标；要顺序用 sorted(s)
if x in nums # 循环里list 查找是 O(n)，先转 set(nums)
s.remove(x)x 不在会报错，不确定时用 s.discard(x)

Python 字典与集合 · 04

defaultdict · Counter

缺键有默认值平均 O(1)collections

易错点

if g[k]:读一下也会插入 k，判断存在用 k in g
defaultdict(list())要传函数本身，写 defaultdict(list)
d[Counter(s)] = ...Counter 不能当键，转 tuple(sorted(c.items()))
只有 26 个小写字母[0] * 26 比 Counter 更快更省

unhashable type: 'list'把 list 当了键，改成 tuple(lst)

怎么选 & 常见搭配

我需要……

判断一个值「见没见过」set
记录 值 → 下标 / 信息dict
按某个特征分组defaultdict(list)

常见搭配

for i, x in enumerate(nums):

边遍历边查 dict / set，一次遍历解决「找配对」

g[tuple(key)].append(x)

defaultdict(list) 分组，key 是 list 时先转 tuple

s = set(nums) 再 x in s

先去重建集合，之后每次查找都是 O(1)

需要一直有序

没有内置有序 dict / set：偶尔排序用 sorted()，频繁取最值用 heapq
