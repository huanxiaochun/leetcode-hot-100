Python 字符串 · 02

str

不可变序列：能读不能改下标 O(1)

易错点

s[0] = 'x'字符串不可变，TypeError；先 list(s) 改完再 "".join
s[l:r] 想取 [l, r]切片左闭右开，取闭区间写 s[l:r + 1]
循环里 s[l:r]每次切片都复制一份，长串上很慢；只记下标，最后切一次
s[100]IndexError；但 s[100:] 返回空串，切片不会越界

Python 字符串 · 03

find / split

查找、拆分、拼接O(len)

易错点

if s.find(t):找到下标 0 时为假，找不到 -1 为真，正好反了；写 if t in s
s.split(" ")连续空格会切出空串；不带参数的 split() 会自动合并空白
s.replace(...) 后 s 没变返回的是新串，要写 s = s.replace(...)
" ".join([1, 2])join 只接受字符串，数字先 map(str, nums)

Python 字符串 · 04

ord / chr

字符和编号互转

易错点

cnt[ord(c) - ord('a')] 遇到大写'Z' 得到 -7，悄悄改到倒数第 7 格（'A' 是 -32 才报错）；字符范围不确定就用 Counter
'5' == 5字符串和数字永远不相等；先 int(c)
"10" < "9"字符串按字典序比，结果是 True；比大小先 int()
d[cnt] = …list 不可哈希，TypeError；写 d[tuple(cnt)]

Python 字符串 · 05

拼接与转换

为什么用 join，不用 +=

易错点

循环里 ans += cCPython 有时会优化，但不保证；长串改用 list + join
int("12abc")整个串必须是数字，否则 ValueError；先 isdigit() 判断
"a" + 1字符串不能直接加数字，TypeError；写 "a" + str(1) 或 f-string
str(list)得到 "[1, 2]" 这种带括号的串；拼成 "12" 要 "".join(map(str, lst))
