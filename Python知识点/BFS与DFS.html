一句话分清：排队 vs 叠盘子

    
两种搜索的代码几乎一样，区别只是「下一个处理谁」：取最早放进去的，还是最晚放进去的

    

      
BFS · 宽度优先 · 队列

        
先来…后来
排队：从队头取，新的排到队尾

        

        
结点上的数字是访问顺序：一层一层往下，同一层从左到右。离起点近的一定先被访问，所以第一次碰到目标时走的就是最短路（每步代价都是 1 时）。

      
DFS · 深度优先 · 栈 / 递归

        
先放…后放
叠盘子：总是拿最上面那个

        

        
先沿着一个孩子一直走到底，走不下去才退回来走下一个孩子。递归函数自带一个栈（调用栈），记着「怎么走回去」。树上的先序 / 中序 / 后序遍历都是 DFS。

    

  

  

    
什么时候用哪个

    
要解决的问题用为什么

      
最少几步能到（每步代价相同）BFS按距离一圈圈往外，第一次碰到就是最短；DFS 找到的路可能绕远

      
按层处理、一分钟一分钟扩散BFS队列里天然是一层一层的；先记下这一层有几个

      
有几个连通块、能不能到达都行只要把能到的都走一遍；DFS 递归最好写

      
列出所有路径 / 方案DFS沿着一条路走，回来时撤销，就是回溯

      
先后依赖：拓扑排序都行BFS：入度为 0 的先出；DFS：后序的逆序

      
树的深度、路径和都行DFS 递归天然带着「从根到这里」的信息

DFS：递归（连通块、能不能到、所有路径）
seen = set()
def dfs(u):
    seen.add(u)                # 进来先标记
    for v in adj[u]:
        if v not in seen:
            dfs(v)

复杂度

    
每个格子 / 结点只进出一次，每条边只看一次

    
时间额外空间空间最坏的时候

      
BFSO(V + E)，网格 O(m·n)队列：最宽的一层空地上的水波一圈比一圈大

      
DFSO(V + E)，网格 O(m·n)递归栈：最长的那条路蛇形走满整个网格，深度 m·n

    

  

  

    
易错点

    
list.pop(0) 当队列每次 O(n)，BFS 会超时；用 deque.popleft()。
出队时才标记同一个格子会被几个邻居重复放进队列。入队时就标记。
递归深度 1000Python 默认最多递归约 1000 层，大网格的 DFS 会报 RecursionError。改用 BFS 或手写栈。
负下标不报错g[-1][c] 会悄悄读到最后一行。先判断范围再访问。
