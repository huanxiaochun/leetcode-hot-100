300. 最长递增子序列

中等 动态规划 LeetCode ↗

状态：dp[i] = 以 nums[i] 结尾的最长递增子序列的长度。nums[i] 能接在左边任何一个比它小的 nums[j] 后面，接在最长的那条后面最好：dp[i] = max(dp[j] + 1)。答案是所有 dp[i] 里最大的。

nums：蓝 正在算的 nums[i]　橙 比它小、能接的 nums[j]　虚线：不比它小，不能接
dp[i]：以 nums[i] 结尾的最长递增子序列有多长（灰色的还没算）

  

  

  



  

    
解题五步

    
所有动态规划题都按这五步想：先把「状态」说清楚，剩下几步就顺了

    
1状态定义
dp[i] = 以 nums[i] 结尾的最长递增子序列的长度一定要「以 nums[i] 结尾」：这样才知道最后一个数是多少，下一个数能不能接上去
2转移方程
dp[i] = max(dp[j] + 1)，j < i 且 nums[j] < nums[i]nums[i] 能接在任何一个比它小的 nums[j] 后面；接在最长的那条后面
橙色：nums[j] < nums[i] 的位置
3初始化
每个 dp[i] = 1nums[i] 自己就是一条长度为 1 的递增子序列
4遍历顺序
i 从左到右，j 在 i 左边子序列只能往后接，所以只看左边
5答案
max(dp[i])，不是 dp[n−1]最长的那条不一定以最后一个数结尾

  

  

    
归纳 · 同类题 · 易错点

    
以 i 结尾的线性 DP可以用二分优化到 O(n log n)

    
152乘积最大子数组
也是「以 i 结尾」，答案也是所有位置取最大。区别：子数组必须连续，只能接在 i−1 后面；子序列可以接在左边任何一个后面
53最大子数组和（普通数组）
「以 i 结尾的最大和」，只看 i−1，O(n)
32最长有效括号
同样是「以 i 结尾」+ 答案取最大

    
答案是 max(dp)[1, 3, 2]：dp = [1, 2, 2]，碰巧对；[3, 4, 1]：dp[2] = 1，但答案是 2。一定要取所有位置的最大
严格递增：用 <相等的数不能接在后面：[7, 7, 7] 答案是 1。条件写成 nums[j] <= nums[i] 会算出 3

  
  

    

      
时间O(n²)

      

        
每个 i×往左看 i 个 j=0 + 1 + … + (n−1)

        
一共比较 n(n−1)/2 次，每次只是比一下大小、取一次 max。n = 2500（题目上限）时大约 300 万次，很快。

dp[5]：7 能接在 2、5、3 后面，max(1, 2, 2) + 1 = 3

    

    

      
空间O(n)

      

        
一个 dp 数组

        
和爬楼梯、打家劫舍不同：dp[i] 要往左看所有 j，不只是前一两格，所以整张表都要留着，不能只用几个变量滚动。

      

    

    

      
对比二分 O(n log n)

      

        
进阶做法：维护 tails[k] =「长度为 k+1 的递增子序列里，最小的结尾」。tails 是递增的，每来一个数用二分找到位置替换，或者接在最后。能把 O(n²) 降到 O(n log n)，但不如 dp[i] 直观，先把这个 dp 吃透再看它。
