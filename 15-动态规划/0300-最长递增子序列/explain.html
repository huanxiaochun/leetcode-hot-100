300. 最长递增子序列

中等 动态规划 LeetCode ↗

状态：tails[k] = 所有长度为 k+1 的递增子序列里，最小的结尾。结尾越小越容易往后接。新数 x 用二分找第一个 ≥ x 的位置：替换它；找不到就接在最后，长度 +1。

nums：蓝 正在处理的数
tails：下标 k 存「长度为 k+1 的递增子序列，最小的结尾」，从左到右一定严格递增
每个 tails[k] 对应的一条子序列（只是帮助理解，代码里不存）

  

  

  



  

    
解题五步

    
所有动态规划题都按这五步想：先把「状态」说清楚，剩下几步就顺了

    
1状态定义
dp[i] = 以 nums[i] 结尾的最长递增子序列的长度页面动画用的是优化版：tails[k] = 长度为 k+1 的递增子序列里最小的结尾
2转移方程
dp[i] = max(dp[j] + 1)，j < i 且 nums[j] < nums[i]nums[i] 能接在任何一个比它小的 nums[j] 后面；接在最长的那条后面
橙色：nums[j] < nums[i] 的位置
3初始化
每个 dp[i] = 1nums[i] 自己就是一条长度为 1 的递增子序列
4遍历顺序
i 从左到右，j 在 i 左边子序列只能往后接，所以只看左边
5答案
max(dp[i])，不是 dp[n−1]最长的那条不一定以最后一个数结尾。tails 版本的答案是 tails 的长度

用 lower_bound严格递增，相等的数不能接在后面：[7, 7, 7] 答案是 1。lower_bound 找第一个 ≥ x，相等时替换；upper_bound 会把 7 接上去，算出 3

对比dp O(n²)

      

        
更直接的 dp：dp[i] = 以 nums[i] 结尾的最长递增子序列长度，dp[i] = max(dp[j] + 1)，j < i 且 nums[j] < nums[i]；答案是所有 dp[i] 的最大值。每个 i 往前扫一遍，O(n²)。tails 的做法把「往前扫」换成了二分。
