279. 完全平方数

中等 动态规划 LeetCode ↗

状态：dp[i] = 和为 i 最少要几个完全平方数。枚举最后一个数 j²，前面要先凑出 i − j²：dp[i] = min(dp[i − j²] + 1)。

dp 表：dp[i] = 凑出 i 最少几个平方数　蓝 正在算　橙 选中的来源　虚线是其他候选

  

  

  



  

    
解题五步

    
所有动态规划题都按这五步想：先把「状态」说清楚，剩下几步就顺了

    
1状态定义
dp[i] = 和为 i，最少要用几个完全平方数
2转移方程
dp[i] = min(dp[i − j²] + 1)，j² ≤ i枚举最后一个平方数 j²：前面那部分要凑出 i − j²，最少 dp[i − j²] 个，再加上这 1 个
每个候选 +1，取最小
3初始化
dp[0] = 0，其余先设为 n凑 0 不需要任何数；全用 1 最多 n 个，所以 n 已经够「大」，取 min 时会被真实值替换
4遍历顺序
i 从 1 到 n 从小到大；j 的顺序无所谓i − j² 比 i 小，已经算好了。平方数能重复用，所以从小往大推正好
5答案
dp[n]

  

  

    
为什么不能直接暴力递归

    
把递推式直接写成递归：同一个子问题会被算很多遍。同色的格子就是重复算的

    
f(12) 试最后一个是 1、4、9，得到 f(11)、f(8)、f(3)；再往下一层，f(7)、f(2) 都出现了两次。只画了两层，越往下重复越多。
f(7) 算了 2 次f(2) 算了 2 次
这棵树有 10 个结点，但不同的子问题只有 8 个。动态规划把每个子问题的答案记下来，每个只算一次：
f(0)f(1)f(2)f(3)f(4)f(5)f(6)f(7)f(8)f(9)f(10)f(11)f(12)

  

  

    
归纳 · 同类题 · 易错点

    
完全背包求凑出某个数的最少个数，每样能用无限次

    
322零钱兑换
一模一样：平方数换成硬币面值。多了一种情况：可能凑不出来，要返回 −1
139单词拆分
同样是「枚举最后一块」，只是最后一块变成了字典里的词，值从「最少几个」变成「能不能」

    
不能贪心挑最大的12 = 9 + 1 + 1 + 1 要 4 个，4 + 4 + 4 只要 3 个。每种「最后一块」都要试
初始值不能是 0取 min 时 0 会把所有候选都压掉。要用一个「不可能达到的大数」，这里 n 就够了

  
  

    

      
时间O(n√n)

      

        
n 个状态×每个试 √i 个平方数

        
和「凑零钱」是同一个模型：平方数是硬币，可以无限用。dp[i − j²] 比 i 小，一定已经算好了。

      

      
12→4²?9 + dp[3]=3+14 + dp[8]=2+11 + dp[11]=3+1
dp[12] 试三种最后一块，取 3

    

    

      
空间O(n)

      

        
dp 数组 n + 1 格

        
初始值用 n：全用 1 凑最多 n 个，所以 n 已经够「大」了，不会溢出。

      

    

    

      
对比贪心不对

      

        
每次挑能用的最大平方数：12 = 9 + 1 + 1 + 1 要 4 个，而 4 + 4 + 4 只要 3 个。也可以用 BFS：从 n 出发每层减一个平方数，第一次到 0 的层数就是答案。还有数学结论（四平方和定理）能做到 O(√n)，面试一般不要求。
