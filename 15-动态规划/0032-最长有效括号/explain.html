32. 最长有效括号

困难 动态规划 LeetCode ↗

状态：dp[i] = 以 s[i] 结尾的最长有效括号子串的长度。以 ( 结尾的一定是 0；以 ) 结尾时，跳过 dp[i−1] 那一段，看前面那个字符 s[j] 是不是 ( 来和它配对。

s：蓝 s[i]　橙 配对的 s[j]　紫 中间那段　绿 j 前面接上的段
dp 表：dp[i] = 以 s[i] 结尾的最长有效长度

  

  

  



  

    
解题五步

    
所有动态规划题都按这五步想：先把「状态」说清楚，剩下几步就顺了

    
1状态定义
dp[i] = 以 s[i] 结尾的最长有效括号子串的长度
2转移方程
j = i − 1 − dp[i−1]，s[j] = '(' 时：dp[i] = dp[i−1] + 2 + dp[j−1]跳过以 i−1 结尾的那一整段（紫），看它前面的 s[j]：是 ( 就和 s[i] 配成一对，把中间包起来；j 前面紧挨着的有效段（绿）直接接上
一段 = 前面的 + ( 中间 )
3初始化
全部为 0以 ( 结尾的、以及找不到 ( 配对的 )，都不可能是有效串的结尾
4遍历顺序
从左到右j − 1 < j < i − 1 < i，用到的都在左边
5答案
max(dp[i])，不是 dp[n−1]有效段可能在中间结束，例如 "()(" 的答案在 dp[1]

  

  

    
归纳 · 同类题 · 易错点

    
以 i 结尾的线性 DP「最后一段」由配对决定

对比栈 O(n)

      

        
另一种常见做法：栈里放下标，先压一个 −1 当「最后一个没配上的位置」。遇到 ( 压栈；遇到 ) 弹栈，栈空了就把当前下标压进去当新的分界，否则长度是 i − 栈顶。暴力枚举所有子串再检查是 O(n³)。
