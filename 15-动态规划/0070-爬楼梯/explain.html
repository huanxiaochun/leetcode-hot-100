70. 爬楼梯

简单 动态规划 LeetCode ↗

状态：dp[i] = 爬到第 i 阶有几种方法。最后一步要么从 i−1 阶跨 1 阶，要么从 i−2 阶跨 2 阶，所以 dp[i] = dp[i−1] + dp[i−2]。

楼梯：台阶上的数字是「走到这一阶有几种方法」，橙色箭头是最后一步
dp 表：蓝 正在算　橙 它要用到的

  

  

  



  

    
解题五步

    
所有动态规划题都按这五步想：先把「状态」说清楚，剩下几步就顺了

    
1状态定义
dp[i] = 从地面出发，爬到第 i 阶一共有几种不同的方法
2转移方程
dp[i] = dp[i−1] + dp[i−2]看最后一步：要么从 i−1 阶跨 1 阶，要么从 i−2 阶跨 2 阶。两类走法不重复也不遗漏，所以相加
第 i 阶只能从这两级上来
3初始化
dp[0] = 1，dp[1] = 1站在地面不动也算 1 种走法；它们前面不够两级台阶，套不了公式，只能直接给。dp[2] = 1 + 1 = 2 正好对
4遍历顺序
i 从 2 到 n，从小到大dp[i] 要用左边两格，左边必须先算好
从左往右填
5答案
dp[n]，而且只用到前两格，所以用两个变量 a、b 滚动就够了

  

  

    
为什么不能直接暴力递归

    
把递推式直接写成递归：同一个子问题会被算很多遍。同色的格子就是重复算的

    
f(5) 要 f(4) 和 f(3)；f(4) 又要 f(3) 和 f(2)…… f(3) 被算了两遍，f(2) 三遍。n 每加 1，结点数就乘上约 1.6 倍，是指数级的。
f(1) 算了 5 次f(2) 算了 3 次f(0) 算了 3 次f(3) 算了 2 次
这棵树有 15 个结点，但不同的子问题只有 6 个。动态规划把每个子问题的答案记下来，每个只算一次：
f(0)f(1)f(2)f(3)f(4)f(5)

  

  

    
归纳 · 同类题 · 易错点

    
线性 DP斐波那契型：当前 = 前两格的组合

    
198打家劫舍
同样只看前两格，但「相加」变成「取较大」：dp[i] = max(dp[i−1], dp[i−2] + 这间的钱)
118杨辉三角
同样是「当前 = 上面两个之和」，只是从一排变成了一个三角形
322零钱兑换
「最后一步跨 1 或 2」推广成「最后一枚硬币是哪种」，相加变成取最小

    
dp[0] 为什么是 1不是「爬 0 阶有 0 种」。站在原地也是一种方案，否则 dp[2] = dp[1] + dp[0] 会算成 1，少了「直接跨 2 阶」
滚动变量的顺序先 c = a + b，再 a = b; b = c。写成 a = b; b = a + b 时，第二句用到的 a 已经是新的了

  
  

    

      
时间O(n)

      

        
i 从 2 走到 n×每次 1 次加法

        
从小往大推：算 dp[i] 的时候，dp[i−1] 和 dp[i−2] 已经算好了，直接拿来用。每个状态只算一次。

      

      
112358
dp[5] = 5 + 3，每个数都是前两个的和

    

    

      
空间O(1)

      

        
只留 a、b 两个变量

        
dp[i] 只依赖前两个状态，更早的以后再也用不到，所以不用开整个数组，两个变量往前滚就够了。

      

    

    

      
对比暴力递归 O(2ⁿ)

      

        
直接写 f(n) = f(n−1) + f(n−2) 而不记结果：f(n−2) 会被 f(n) 和 f(n−1) 各算一遍，越往下重复越多，调用次数像斐波那契数一样指数增长。重复子问题就是 dp 要解决的事：每个子问题只算一次、记下来。

      

      
f5→f4f3→f3f2f2f1
f3 算了两次，f2 算了三次……
