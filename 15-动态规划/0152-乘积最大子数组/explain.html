152. 乘积最大子数组

中等 动态规划 LeetCode ↗

状态：mx[i] / mn[i] = 以 nums[i] 结尾的子数组，乘积最大 / 最小是多少。要连最小的一起记：乘上一个负数，最小的会翻身变成最大的。

nums：蓝 当前的数 x
mx[i]：以 nums[i] 结尾的最大乘积
mn[i]：以 nums[i] 结尾的最小乘积（遇到负数时它可能变成最大的）

  

  

  



  

    
解题五步

    
所有动态规划题都按这五步想：先把「状态」说清楚，剩下几步就顺了

    
1状态定义
mx[i] / mn[i] = 以 nums[i] 结尾的子数组，乘积的最大值 / 最小值
2转移方程
mx[i] = max(x, mx[i−1]·x, mn[i−1]·x)mn[i] 同理取 min。以 x 结尾的子数组要么只有 x 自己，要么接在以 i−1 结尾的那段后面
x 为负数时，最小的会变成最大的
3初始化
mx = mn = ans = nums[0]以第一个数结尾的子数组只有它自己
4遍历顺序
从左到右子数组连续，只能接在 i−1 后面
5答案
max(mx[i])，用 ans 一路记下来

  

  

    
归纳 · 同类题 · 易错点

    
以 i 结尾的线性 DP同时维护最大和最小两个状态

    
53最大子数组和（普通数组）
同一个套路，只记最大就够：加一个数不会让「最小的」突然变成「最大的」，乘法会
300最长递增子序列
也是「以 i 结尾」，但子序列不连续，要往左看所有 j

    
为什么要记最小[-2, 3, -4]：以 3 结尾最大是 3、最小是 −6；乘上 −4 后，−6 × −4 = 24 才是最大。只记最大会得到 3
先算 a、b 再更新a = mx * x, b = mn * x 先算好，再更新 mx、mn。直接写 mx = max(...) 后，算 mn 时用到的已经是新 mx

  
  

    

      
时间O(n)

      

        
每个数→算 3 个候选，取 max 和 min

        
和「最大子数组和」一样，按以 i 结尾来分类。不同的是乘法里负负得正，只记最大不够：上一步最小的（很负的）乘上一个负数，会变成最大的。

      

      
-23-4mn[1] = -6→-6 × -4 = 24
最小值翻身成最大值

    

    

      
空间O(1)

      

        
只用到上一步的 mx、mn

        
注意先用旧的 mx、mn 算出 a、b，再更新：直接写 mx = max(mx * x, …) 会让后面算 mn 时用到新的 mx。

      

    

    

      
对比暴力 O(n²)

      

        
枚举所有起点、终点，边乘边更新答案是 O(n²)。只记 mx 不记 mn 的写法在 [-2, 3, -4] 上会算出 3，正确答案是 24。
