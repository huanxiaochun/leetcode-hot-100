C++ 二维数组与网格 · 02

创建与传参

m 行 n 列：外层是行，内层是列下标 O(1)#include <vector>

易错点

g[j][i] 写反第一个下标是行、第二个是列；习惯写 g[i][j]，i 配 m、j 配 n
空矩阵 g[0].size()g 没有行时越界；题目没保证非空就先判 g.empty()
void f(vector<vector<int>> g)按值传会拷贝整个矩阵，递归里很慢；写 &
vector<vector<int>> g(m)只有 m 个空行，g[i][j] 越界；要写 vector<int>(n)

C++ 二维数组与网格 · 03

遍历

按行最常见，其它方向靠下标O(mn)

易错点

for (auto row : g) row[0] = 1;row 是拷贝，g 没变；改原矩阵写 auto& row
按列时 i < n列遍历里 i 是行号，上限是 m；m ≠ n 时最容易错
转置时 j 从 0 开始每对 (i, j)、(j, i) 会被交换两次，等于没换；j 从 i + 1 开始
边遍历边置 0新置的 0 会被当成原来的 0 继续扩散；先记录，再统一修改

C++ 二维数组与网格 · 04

原地变换

转置、翻转、旋转：都是 swapO(n²)#include <algorithm>

易错点

非方阵原地转置行列数变了，原地放不下；新开 n × m 的矩阵
顺时针写成上下翻转转置后左右翻转是顺时针，上下翻转是逆时针；拿 2×2 验证一下
swap 整行很慢？vector 的 swap 只交换内部指针，O(1)，放心用
reverse(g[i])reverse 要传迭代器，写 reverse(g[i].begin(), g[i].end())

方向与边界

上下左右四个邻居，先判越界再访问

易错点

先访问 g[x][y] 再判越界x = -1 时已经越界读内存；越界判断写在前面
x <= m下标最大是 m − 1，判断写 x >= m 才算越界
i * m + j压成一维要乘列数 n，乘行数会冲突
dx、dy 顺序不一致两个数组要一一对应；按顺时针写，右转就是 d + 1
