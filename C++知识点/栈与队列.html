C++ 栈与队列 · 02

stack

栈：后进先出，只能看栈顶O(1)#include <stack>

易错点

int x = st.pop();pop() 不返回值，先 st.top() 再 st.pop()
空栈 st.top()未定义行为，先判 !st.empty()
for (int x : st)stack 不能遍历；要遍历就用 vector 当栈
单调栈存值后面要算距离或写回答案时没有下标；一般存下标

queue

队列：先进先出，队头出、队尾进O(1)#include <queue>

易错点

q.top()queue 没有 top，队头是 q.front()
for (k < q.size())循环里还在 push，size 一直变；先存到 sz
auto& u = q.front(); q.pop();pop 后引用失效；按值取 int u = q.front()
BFS 出队时才标记访问同一个点会被重复入队；入队时就标记

C++ 栈与队列 · 04

deque

双端队列：两头都能 O(1) 进出两端 O(1)#include <deque>

易错点

vector 头部删除erase(begin()) 是 O(n)；要两头进出用 deque
空 deque 的 front()未定义行为，先判 empty()
单调队列先判过期新元素还没入队时队列可能为空；先入队再判过期最稳
<= 还是 <取最大值时用 <= 把相等的也弹掉，队列更短

C++ 栈与队列 · 05

priority_queue

堆：top 永远是最大（或最小）O(log n)#include <queue>

易错点

以为默认是小顶堆默认 top 是最大值；要最小值写 greater<int>
cmp 写反比较函数返回 true 表示 a 优先级更低；a > b 才得到小顶堆
想遍历或改中间的元素堆只能看 top；要删任意元素用 multiset
int x = pq.pop();pop() 不返回值，先 top() 再 pop()

常见搭配

int u = q.front(); q.pop();

取值和删除是两步：先看再删，stack、queue、priority_queue 都一样

while (!st.empty() && …) st.pop();

单调栈 / 单调队列：每个元素最多进出一次，总共 O(n)

pq.push({-dist, node})

存负数把大顶堆当小顶堆用，省掉 greater 的长类型

while (!pq.empty()) pq.pop();
