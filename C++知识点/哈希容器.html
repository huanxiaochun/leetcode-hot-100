C++ 哈希容器 · 02

unordered_map

哈希表：键 → 值平均 O(1)#include <unordered_map>

易错点

if (m[k])会把 k 插进去，判断存在用 m.count(k)
m.at(k)k 不存在会抛异常，不确定时先 find
遍历时 erase(it)it 会失效，写成 it = m.erase(it)
pair 当键没有默认哈希，编译报错，改用 map 或编码成 long long

C++ 哈希容器 · 03

unordered_set

哈希集合：只存键，自动去重平均 O(1)#include <unordered_set>

易错点

想改某个元素元素是只读的，先 erase 再 insert
s.contains(x)C++20 才有，C++17 下用 s.count(x)
依赖遍历顺序顺序不固定，要有序用 set
遍历时 insert可能触发扩容，迭代器全部失效

C++ 哈希容器 · 04

map

有序表：键从小到大排好O(log n)#include <map>

易错点

m[k] 同样会插入只读时用 count / find
std::lower_bound(m...)在 map 上是 O(n)，用成员 m.lower_bound(k)
空表取 begin / rbegin解引用会崩，先判 m.empty()
不需要顺序也用 map慢一截，换 unordered_map

C++ 哈希容器 · 05

set

有序集合：排好序 + 去重O(log n)#include <set>

易错点

ms.erase(x)删光所有 x，只删一个用 ms.erase(ms.find(x))
std::lower_bound(s...)在 set 上是 O(n)，用成员 s.lower_bound(x)
空集合 *s.begin()未定义行为，先判 s.empty()
*it = 新值元素是只读的，先 erase 再 insert

C++ 哈希容器 · 06

怎么选 & 常见坑

我需要……

判断一个数「见没见过」unordered_set
记录 值 → 下标 / 次数unordered_map
把东西按某个特征分组unordered_map
按顺序遍历 / 找第一个 ≥ xmap / set
随时拿最大、最小值set / multiset
键只是 0~25 或很小的整数数组 int[26]

容易踩的坑

if (m[k]) 判断存在

会把 k 插进去，改用 m.count(k) 或 m.find(k)

遍历时直接 m.erase(it)

it 会失效，写成 it = m.erase(it)

unordered_map<pair<int,int>, int> 编译报错

pair 没有默认哈希，改用 map，或把两个数编码成 long long

遍历 unordered_map 依赖顺序

顺序不固定，需要顺序就用 map 或先排序
