C++ 回溯 · 02

回溯模板

一棵决策树：根是「什么都没选」，每条边是一次选择指数级

易错点

忘了 pop_back兄弟分支会带着上一个分支的选择，结果越来越长
res.push_back 后 path 还在变push_back(path) 是拷贝，没问题；存指针或引用才会出错
结束后没有 return叶子还会继续往下 for，可能越界或多收集
dfs 参数传值的 vector每层都拷贝一份，慢很多；path 用成员变量或引用

C++ 回溯 · 03

排列：used 数组

每个位置可以放任何没用过的数，顺序不同算不同的答案O(n·n!)

易错点

排列也用 startstart 只往后选，[2,1] 这种顺序永远选不到
used 只设不恢复回到上一层后这个数一直显示用过，后面的分支全被跳过
去重条件写成 used[i-1]!used[i-1] 才表示「同一层」的前一个；写反也能对但剪得少
去重前没排序相同的数不相邻，a[i] == a[i-1] 判断不出来

C++ 回溯 · 04

组合与子集：start 下标

顺序无关：[1,2] 和 [2,1] 是同一个，所以只往后选O(n·2ⁿ)

易错点

dfs(start + 1)应该是 dfs(i + 1)：下一层从「刚选的这个」后面开始
子集只在叶子收集会漏掉中间节点，子集是每个节点都算
break 前没排序后面可能还有小的数，break 会漏答案；没排序只能 continue
可重复选传 i+1每个数最多只能用一次了；能重复选要传 i

C++ 回溯 · 05

切割：start 就是切割线

把字符串切成几段：每一层决定「这一段切到哪」O(n·2ⁿ)

易错点

substr 第二个参数当结尾substr(pos, len) 第二个是长度：end - start + 1
每次都现算回文同一段会被判断很多次；先用 dp 预处理成 O(1)
结束条件写 start == n - 1最后一段还没切出来；要等 start == n
生成类不剪枝先生成所有串再检查合不合法，多做指数倍的工作

C++ 回溯 · 06

网格与棋盘

在格子上走：标记「正在用」，回来时恢复O(m·n·3ᴸ)

易错点

标记后不恢复和「岛屿」那种只要访问一次的 DFS 不同，回溯里别的路径还要再走这一格
先改标记再判断越界越界访问 g[r][c] 直接崩；先判断越界
r - c 当下标可能是负数；加上 n 偏移
找到后不提前返回只要判断「有没有」时，找到一条就 return true，不用把树走完

C++ 回溯 · 07

图解：一次完整的回溯

全排列 [1, 2, 3]：每个结点是当前的 path，每条边是一次选择

决策树当前路径　到底了，收集　撤销后试的下一个分支

[ ] → [1] → [1,2] → [1,2,3] 到底，收集；回来时 pop_back() 撤销 3、撤销 2，path 变回 [1]，才能去试 [1,3]。每个结点都是「做选择 → 递归 → 撤销」这三步

记住

path 只有一份所有分支共用同一个 path，所以回来时必须撤销
撤销的顺序后选的先撤销，和栈一样：path 就是从根到当前结点的路
收集时要拷贝收集的是那一刻的 path，之后它还会变
复杂度≈ 结点数 × 每个结点的工作；排列叶子有 n! 个

C++ 回溯 · 08

图解：三种树

同样是 [1, 2, 3]，区别只在「每层能选什么」和「什么时候收集」

子集下一层从 i + 1 开始

只往后选，所以不会出现 [2,1]。每个结点都是一个子集：进来就收集

组合（选 2 个）只收集第 2 层

和子集是同一棵树，只在 path 长度到 k 时收集。[3] 后面没有数了，凑不够 2 个

排列（选 2 个）每层从 0 开始

顺序不同算不同，所以每层都要看所有数；用过的靠 used 跳过

记住

顺序无关组合、子集用 start，下一层从 i + 1 开始
顺序有关排列用 used，每层从 0 开始
能重复选下一层传 i 而不是 i + 1
收集时机子集：每个结点；组合 / 排列：长度够了才收

C++ 回溯 · 09

图解：剪枝和切割

剪枝越早越好：在「做选择之前」就判断，整棵子树都不用走

组合总和：排序后 break候选 [2, 3, 5]，凑 5，同一个数能重复用

排过序，第一个就超过剩余了，后面的只会更大，直接 break。「剩 3」下面还能再选 2：能重复选，下一层传的是 i

分割回文串：start 是切割线"aab" 切成几段，每段都是回文

每一层决定「这一段切到哪」。不是回文的那一刀直接跳过；切到末尾就是一种方案：a|a|b、aa|b

记住

break 的前提数组排过序；没排序只能 continue
剪枝放哪里for 循环里、递归之前；不要等到叶子再判断
切割 = 组合选「切在哪」就是在下标里选，用 start
判断很慢就预处理回文这种判断先用 DP 打表，回溯里查表 O(1)
