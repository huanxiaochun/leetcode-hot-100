T*

指针存的是地址，-> 是「解引用再取成员」nullptr 是 C++11

易错点

ListNode* a, b;b 不是指针而是 ListNode；每个都写星号 ListNode *a, *b;
p->next->valp 或 p->next 为空就崩；先判 p && p->next
a == b 判断相同节点这本来就是比较地址；比较值要写 a->val == b->val
int* p; *p = 1;没初始化的指针指向随机地址；声明时就赋值或给 nullptr

易错点

delete 之后还用 del内存已经还回去，再访问是未定义行为；delete 放在最后

struct 末尾没写分号}; 的分号不能少，否则报一串奇怪的错
new 了不 delete刷题一般不扣分，工程里会内存泄漏；自己的代码谁 new 谁 delete

dummy

哨兵：在头节点前面放一个假节点

易错点

return &dummy;哨兵是假节点，答案是 dummy.next
ListNode* dummy;只声明了一个指针，没有节点；写 ListNode dummy; 再取 &dummy
dummy.next 和 dummy->next对象用点，指针用箭头；dummy 是对象，tail 是指针
return 前 delete &dummy栈上的对象不能 delete；只 delete new 出来的

改指针的顺序

先存下一个，再改指向

易错点

cur->next = prev; cur = cur->next;已经改成指向 prev，往回走了；先存 nxt
p->next = x; x->next = p->next;第二句的 p->next 已经是 x，x 指向自己；先连后面
while (fast->next)fast 自己可能是 nullptr；写 fast && fast->next
有环链表转数组for 循环永远停不下来；测试有环时按节点个数计数

常见搭配

for (ListNode* p = head; p; p = p->next)

unordered_map<int, Node*> + 双向链表
