数组怎么看成一棵树

    
堆是一棵完全二叉树：一层一层从左往右排满。所以不需要指针，直接按下标存在数组里

    

      
下标关系（从 0 开始）
父亲     (i - 1) / 2
左孩子   2 * i + 1
右孩子   2 * i + 2
叶子     i >= n / 2
n 个结点的树只有 ⌊log₂n⌋ + 1 层，所以上浮、下沉最多走 log n 步。

      
堆只保证一件事
小顶堆：父亲 ≤ 孩子，堆顶是最小值。大顶堆：父亲 ≥ 孩子，堆顶是最大值。
兄弟之间、不同子树之间没有顺序：数组里第二个数不一定是第二小，想要第二小只能先把堆顶 pop 掉。

    

  

  

    
各操作的代价

    
为什么建堆是 O(n)：一半的结点是叶子不用动，四分之一只沉 1 层，八分之一沉 2 层……加起来 n/4·1 + n/8·2 + n/16·3 + … < n

    
操作怎么做时间
看堆顶 top()就是 a[0]O(1)
放进去 push(x)放到最后，上浮O(log n)
取堆顶 pop()最后一个补到堆顶，下沉O(log n)
建堆 priority_queue pq(a.begin(), a.end())从 n/2 − 1 往前逐个下沉O(n)
一个个 push 建堆n 次上浮O(n log n)
查找 / 删除任意元素堆不支持，要遍历O(n)

  

  

    
在 C++ 里用：priority_queue

    
默认是大顶堆；比较器的意思是「返回 true 的那个排在下面」，所以 greater 反而是小顶堆

    

      
三种常见写法
// 大顶堆
priority_queue<int> big;
// 小顶堆
priority_queue<int, vector<int>, greater<int>> small;
// pair：先比 first 再比 second
using P = pair<int, int>;
priority_queue<P, vector<P>, greater<P>> pq;

      
自定义比较
auto cmp = [](ListNode* a, ListNode* b) {
    return a->val > b->val;   // a 大就排下面：小顶堆
};
priority_queue<ListNode*, vector<ListNode*>,
               decltype(cmp)> pq(cmp);

    

  

  

    
常见套路

    

      
Top-K：第 k 大 / 前 k 个
开一个小顶堆只留 k 个，超过就 pop 掉堆顶。堆顶是「进前 k 的门槛」，最后堆顶就是第 k 大。时间 O(n log k)，比整体排序省。

      
两个堆：动态中位数
大顶堆放较小的一半，小顶堆放较大的一半，两边个数差不超过 1。中位数只看两个堆顶。

      
多路归并：合并 K 个有序序列
堆里放每一路当前最前面的那个，每次 pop 最小的，再把它那一路的下一个放进来。堆里始终只有 K 个，总共 O(N log K)。

      
堆排序
建堆 O(n)，再 n 次把堆顶换到最后、下沉。原地、最坏 O(n log n)，但不稳定。

    

  

  

    
易错点

    
greater 是小顶堆比较器回答「a 是不是应该排在 b 下面」。less（默认）让大的在上，greater 让小的在上。
空堆不能 top / poppq.top()、pq.pop() 前先判 !pq.empty()，否则是未定义行为，不会报错。
不能遍历、不能改priority_queue 没有迭代器，也不能改里面的值。要删任意元素用 set，或者做「懒删除」：先记下来，等它到堆顶时再扔。
lambda 要传两次模板参数写 decltype(cmp)，构造时还要把 cmp 传进去；C++20 之前漏掉构造参数会编译失败。
