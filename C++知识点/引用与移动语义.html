T&

引用：变量的另一个名字

易错点

auto x = r;auto 会去掉引用，x 是拷贝；要引用写 auto& x = r
int& r = 5;普通引用不能绑字面量，用 const int& 或直接 int
int& f() { int x; return x; }返回局部变量的引用，函数结束 x 就没了，按值返回
int& e = v[0]; v.push_back(1);vector 扩容后 e 指向旧内存，push_back 后重新取

C++ 引用与移动语义 · 03

for (x : v)

范围 for：逐个取出容器里的元素C++11

易错点

for (auto x : v) x = 0;x 是拷贝，v 没变；要改元素写 auto& x
for (string s : strs)每个字符串都拷贝一次，只读用 const string&
循环里 v.push_back()扩容后迭代器失效，可能崩溃，改用下标循环
pair<int,int>& p : mmap 元素是 pair<const K, V>，类型不对会报错，写 auto&

const T&

函数传参：拷贝、可改、只读

易错点

dfs(vector<int> path)递归每层都拷贝一次数组，容易超时，传 vector<int>&
const map 上用 m[k][] 可能插入，const 下编译报错，用 find / at
const int& x小类型拷贝更便宜，直接写 int x
vector<int>& f()返回局部数组的引用会悬空，按值返回 vector<int>

std::move

移动语义：把内存交出去，不复制#include <utility>

易错点

move 之后再读 s内容不确定，只能重新赋值或销毁
std::move(const 对象)const 不能被搬，悄悄退化成拷贝
return std::move(ans);反而挡住编译器优化，直接 return ans
std::move(int)小类型移动 = 拷贝，没意义

怎么选 & 常见搭配

我想……

遍历时只读const auto&
遍历时修改元素auto&
遍历 int 这种小类型auto
函数参数，只读大对象const T&
函数里改调用方的变量T&
变量之后不用了，放进容器std::move

常见搭配

for (auto& x : v) out.push_back(std::move(x));

把元素搬进另一个容器，一次都不拷贝；之后 v 里的元素别再读

for (const auto& [k, val] : m)

只读遍历 map，键值对都不拷贝

void dfs(vector<int>& path)

递归每层共用同一个数组，进去 push_back，回来 pop_back

for (auto x : v) out.push_back(std::move(x));

x 已经是拷贝，move 只省掉第二次；要真正不拷贝，循环变量写 auto&
