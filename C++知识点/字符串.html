C++ 字符串 · 02

string

可变字符串：下标 O(1)，尾部追加 O(1)下标 O(1)#include <string>

易错点

s = s + c每次复制整个串，循环里会变 O(n²)；写 s += c
"a" + "b"两个字面量是 char 指针，不能相加；至少一边是 string("a")
s == 'a'string 不能和 char 比较，写 s == "a" 或 s[0] == 'a'
空串 s.back()未定义行为，先判 !s.empty()

C++ 字符串 · 03

substr / find

截取和查找：第二个参数是长度O(len)#include <string>

易错点

s.substr(l, r)第二个参数是长度，取 [l, r] 要写 substr(l, r - l + 1)
if (s.find(x))找到下标 0 时为假、找不到时 npos 为真，正好反了；和 npos 比
int p = s.find(x)npos 转 int 变成 -1，能用但容易混；判断时直接和 npos 比
循环里 s.substr每次都复制一份子串，长串上很慢；只记 start、len，最后截一次

C++ 字符串 · 04

char

字符就是 0~127 的整数O(1)#include <cctype>

易错点

cnt[c - 'a'] 遇到大写'A' - 'a' = -32，越界；不确定字符范围就开 128 直接用 cnt[c]
cout << 'a' + 1输出 98 而不是 b，要字符写 char('a' + 1)
中文 / é 当下标char 有符号，UTF-8 字节是负数；转 (unsigned char)c
'5' == 5字符 '5' 是 53；比数字先 c - '0'

C++ 字符串 · 05

stoi / to_string

数字 ↔ 字符串、按分隔符拆分#include <string>

易错点

stoi("abc")开头不是数字直接抛异常；不确定输入时先判断或手动解析
stoi("99999999999")超出 int 抛 out_of_range，用 stoll
x = x * 10 + c忘了减 '0'，加的是 ASCII 码；写 c - '0'
to_string(char)char 被当成整数，to_string('a') 是 "97"；要单字符串写 string(1, c)
