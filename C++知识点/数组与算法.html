C++ 数组与算法 · 02

vector

动态数组：连续内存，随下标访问下标 O(1)#include <vector>

易错点

v[i] 越界不报错也不检查，可能读到垃圾值，调试时改用 v.at(i)
空数组 v.back()未定义行为，先判 !v.empty()
循环里 v.erase(i)每次 O(n)，整体变 O(n²)；用双指针覆盖写再 resize
vector<int> v(n); v.push_back(x)已经有 n 个 0 了，x 排在第 n+1 个；只想预留空间用 reserve(n)

C++ 数组与算法 · 03

sort

排序：默认升序，可传比较函数O(n log n)#include <algorithm>

易错点

return a <= b;比较函数必须是严格小于，写 <= 可能越界崩溃
sort 传入的参数会改掉原数组，调用方还要用原顺序就先拷贝一份
lambda 参数写 auto a每次比较都拷贝元素，二维数组写 auto& a
sort 后找原下标下标已经变了，需要原下标就排 {值, 下标} 的 pair

C++ 数组与算法 · 04

<algorithm>

常用小工具：交换、最值、反转、去重#include <algorithm>

易错点

max(a, 1LL)两边类型必须一样，int 和 long long 混用编译报错，写 max(1LL * a, b)
unique 之后 v.size()unique 不改长度，要配合 erase 才真正删掉
accumulate(…, 0)初值是 int，和超出 int 会溢出，用 0LL
max_element 空数组返回 end()，解引用会崩，先判空

C++ 数组与算法 · 05

size_t

下标与长度：size() 是无符号数

易错点

i < v.size() - 1空数组时右边是超大数，循环会越界；写 i + 1 < v.size()
size_t i; i >= 0无符号永远成立，倒序循环用 int
long long y = a * ba * b 先按 int 算已经溢出，写 1LL * a * b
int mid = (l + r) / 2l + r 可能溢出，写 l + (r - l) / 2
